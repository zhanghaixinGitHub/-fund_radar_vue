# 站内提醒改版需求与实施

## 页面结构

站内提醒继续使用顶部一级入口和统一的左侧栏目。窄屏沿用“栏目”抽屉。

| 分组 | 栏目 | 内容 |
| --- | --- | --- |
| 提醒消息 | 全部消息 | 默认栏目，来自现有两类消息记录，按最近变化时间统一排序，支持只看未读及按基金直达。 |
| 提醒消息 | 止盈与下跌提醒 | 本人设置的止盈、持仓亏损和净值高点回撤。仅显示实际形成的对应消息。 |
| 提醒消息 | 基金事件提醒 | 已发送的基金及相关公司公告、公告复查。重大事件标识依赖已核实的分类。 |
| 提醒消息 | 走势与风险提醒 | 走势判断变化与原有风险规则触发消息。 |
| 提醒消息 | 持仓检查 | 既有资金安排复查、用款到期及其他持仓复查。每日检查反馈单独核实消息来源后接入。 |
| 提醒设置 | 关注提醒设置 | 集中管理已关注基金的规则，保留原有开关、权限及可用状态。 |
| 提醒设置 | 持仓提醒设置 | 管理当前“我的持仓”里具体基金的阈值。 |

## 使用路径

- 我的关注详情保留原设置栏目地址，名称改为“提醒设置”，可以直达这只基金的消息。市场、经理和分析页保持现有入口。
- 我的持仓总览保留账户操作。单只基金的持仓详情在“定投计划”后提供“提醒设置”栏目，直接管理当前基金。也可在“站内提醒 → 持仓提醒设置”集中管理，两处共用同一套设置。
- 两处均按止盈、持仓亏损、高点回撤三行展示。点击任一项只编辑并保存该项，首次也可以单独保存。系统参考、百分比输入和保存都在抽屉内。切换下跌计算方式前提示原下跌条件将被替换。
- 消息保留原触发解释、已读状态、复查状态与变化历史。读取与标记已读按本人权限处理。

## 实施和验收

- 消息按类别、基金、已读状态在服务端筛选后分页，避免只筛当前页。普通提醒按触发时间排序，复查提醒按最近变化时间排序。
- 保留旧消息和设置地址。使用现有数据库表及已读接口。新增分类只读取记录，运行计划、提醒条件和交易行为沿用现行授权。
- 当前已找到公告、资金安排复查的站内来源。止盈与下跌已有设置和条件判断，未确认存在持久化投递。每日持仓检查已有独立反馈，待接入站内消息。缺少消息来源时显示真实空态。
- 遵循前端 `DESIGN.md`。检查栏目切换、历史链接、空态、错误、分页、已读权限与窄屏导航。
