# 基金雷达 — 同步中心手动触发与进度需求

> 关联设计：`docs_zhx/design/sync-center-tasks.md`
> 关联测试：`docs_zhx/testcase/sync-center-tasks.md`
> 版本：v1.0
> 日期：2026-08-28
> 变更等级：L2

## 1. 目标与范围

管理员在“数据同步中心”中可查看基金市场同步任务、手动发起任务、实时查看服务端进度，并查看任务最近一次完整成功的同步时间。

本期包含两项任务：

| 任务 | 自动计划 | 管理员手动入口 |
| --- | --- | --- |
| 基金市场净值增量同步 | 工作日 20:00 | 是 |
| 基金市场完整资料同步 | 不自动执行 | 是 |

完整资料同步范围固定为已登记的 `ACTIVE + TUSHARE_PRO_FUND` 基金市场，包含基础资料、扩展净值、基金经理、规模和分红；不读取个人关注关系，不执行交易。

## 2. 交互与状态

每张任务卡必须展示任务名称、用途、当前状态、开始/结束时间、读取/新增/更新/跳过统计、进度条和当前处理基金。进度百分比只能根据服务端实际完成数计算；总数尚未确定时展示 `0 / 0`，不得伪造百分比或假动画。

任务卡上的“上次成功同步时间”必须来自 `source_sync_run` 中对应父运行记录的 `SUCCEEDED + finished_at`，不能仅保存在 Python 进程内。没有成功记录时显示“尚未成功同步”。

原“查看基金市场”链接从同步卡移除。

## 3. 边界与异常

- 只有具备 `SYNC_JOB_START` 的管理员可以创建任务；具备 `SYNC_JOB_READ` 的管理员可以读取进度和历史成功时间。
- 浏览器只能访问 Java `/api/v1/sync-jobs/*`；Java 使用服务令牌访问 Python `/internal/v1/funds/sync-jobs/*`；浏览器不得直接访问 Python 或 Tushare。
- 同一时刻只允许一个市场同步任务运行。重复点击或跨任务并发时返回稳定冲突，不重复请求 Tushare、不重复写库。
- 完整资料任务的五个阶段各自保留来源运行记录；只有全部成功时父运行 `MARKET_DETAIL` 才标记成功。任一阶段失败时不得更新“上次完整资料同步成功时间”。
- 当前完整资料任务暂不增加定时计划：它会调用多个 Tushare 接口，需先完成真实权限、频率和额度验证后再单独评审自动刷新策略。

## 4. 验收标准

1. 两张任务卡均可由管理员手动触发；任一任务运行时两张卡的按钮都不可重复提交。
2. 页面每秒轮询一次运行中任务，进度、阶段描述、当前基金和最终统计来自服务端真实状态。
3. 后端重启后，页面仍能通过 `source_sync_run` 显示各任务最后一次完整成功时间。
4. 任务失败、权限不足、Python 服务不可用和同步冲突均展示安全中文提示，不暴露服务令牌、Tushare Token 或原始响应。
