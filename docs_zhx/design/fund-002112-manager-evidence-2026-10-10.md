# 002112 一日预测的经理变更与任期表现

## 目标与范围

将基金经理变更及公开原因、当前经理的任期表现纳入同一次一日综合判断，并在原有依据区域呈现。
仅接入 002112 的综合分析入口；其他基金及五日、二十日、半年预测不沿用本次未经对应验证的评价。
不重写旧预测，不恢复定时采集，不增加数据采购或外部来源。

## 输入与判断规则

- 经理变更作为持续背景，独立于普通公告的最近十四天及一百份上限。读取已保存、哈希核验通过、
  原文明示本基金且接收时刻不晚于分析截止的原件；公开日期采用正文中的公告送出日期。
- 公开原因逐字保留，不推断业绩压力、内部矛盾或其他未公开隐情。原文或字段无法核实时标记缺口。
- 当前团队以截止时已保存的任职表与最新已生效变更公告交叉核对；冲突时不评价个人表现。
- 参与管理期间和当前独立管理阶段分开。共同管理的基金表现不能全归于个人；交接当日不全部归属
  留任者，独立阶段从其他经理离任次日起的首个交易日收盘计算。
- 收益使用现有来源的复权单位净值，不能用累计净值比值或未复权净值替代。原始日期、净值、版本
  摘要、任职行及公告正文保留在本次不可变输入快照。
- 每个区间计算末值/首值减一的收益、相对区间峰值的最大回撤，以及滚动二十日正收益窗口占比。
  后者是重叠历史窗口的描述，不是预测胜率。少于二百五十二个交易日收益观测明确提示样本较短。
- 缺交易日、缺复权值、重复日期或无效数值时停止该区间计算，不填零、不插值。不把样本短等同能力差。
- 目前没有本基金合同基准的可比序列及同类比较，不拿大盘替代其合同基准，不生成能力评分、排名
  或已经验证的超额能力结论。经理表现可以影响历史业绩参考性和判断把握，不能机械决定次日方向。

## 契约与页面

Python 在原事实字典增加 `manager:change`、`manager:profile`、`manager:performance`，显示类别为
“基金经理”。变更和表现事实必须被综合结果实际引用，遗漏进入现有有界纠正，仍遗漏则拒绝保存。
经理因素的作用仅允许“背景观察”或“双向影响”；直接行情依据仍需解释最终方向。

保留原十六项资料清单；D01 展示经理覆盖及比较缺口，D12 说明长期经理公告另行保留。前端只扩展
合法业务类别，继续校验基金、周期、记录编号和来源链接。Java 原有引用与正文核对可兼容新增事实，
不新增接口或表。分析版本更新，旧记录仍读取原事实，不事后补入新资料。

有效输入身份包含实际使用的任职和净值版本，不因单纯检查时刻变化制造新版本。

## 验证要求

验证旧公告持续纳入、公开原因与原文一致、未来资料排除、任职冲突、共管与独管分段、复权收益和
回撤公式、缺值及交易日缺口、经理事实强制引用、页面类别及危险链接拒绝、旧记录不变。
真实验证分为本地数据快照、实际分析生成、Java 归档回读和页面展示，不能用单测代替后续阶段。

数据口径来源：[Tushare 公募基金净值字段说明](https://tushare.pro/document/2?doc_id=119)。
