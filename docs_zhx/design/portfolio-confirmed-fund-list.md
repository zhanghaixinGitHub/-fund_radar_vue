# 持仓名单补列约定

2026-11-02 补充：用户明确按截图重置金额和历史后，显式采用的截图基数优先展示，详细口径见[按截图重置个人持仓](portfolio-screenshot-reset.md)。旧名单补列仅用于没有明确基数的账户。

`GET /api/v1/sim-portfolios/current` 和管理员对应的本人持仓总览增加 `unrecordedHoldings`，每项仅含 `fundCode`、`fundName`。

- 来源是目标用户最新一次 `USER_CONFIRMED_SCREENSHOT` 快照，且基金仍在该用户关注中、尚不存在该用户的 `sim_position`。按 `imported_at`、`snapshot_id` 降序唯一选取快照，不合并旧快照，不跨用户读取。
- `positions`、资产汇总、交易、收益历史和定投口径不变。补列只负责名单完整性，不读取历史截图金额，不推算份额，不创建模拟买卖，也不将未知值填零。
- 前端合并两份名单，已有模拟持仓优先，同基金去重；补列基金显示名称、代码和“暂无模拟持仓数据”，不提供依赖账本的收益入口或交易按钮。金额排序时未知值排在所有已知值之后，包含亏损值。
- 旧响应缺少该字段时视为空数组。取消关注会移除尚无账本的补列条目；已存在的模拟账本和历史记录保留。

验收覆盖本人/其他用户、最新/旧快照、已关注/未关注、已有账本去重、无隐式买入和金额排序。真实名单变更应在事务中调用既有关注服务，保留积分释放和审计，并在变更前备份。
