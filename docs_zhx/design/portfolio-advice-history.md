# 持仓操作建议与每日留档

## 本次范围与页面

持仓卡片在份额说明与操作按钮之间展示「建议继续持有 / 建议卖出」、理由摘要及完整依据、历史记录入口。独立持仓分析页分为最新建议、历史记录、效果回看；不单独展示预测方向或概率模块，不改变关注页。没有可用依据或尚无已确认份额时显示具体原因，不默认当成继续持有。

第一版使用已有 `DIRECTION_PAGE_TRIAL_V1` 实验模型，不训练、不发布新模型。固定主模型 `DROP_60D_GROUP_L2` 的分数大于 0.5 时建议继续持有，否则建议卖出；这是用户要求的初步参考规则，不是经过验证的交易策略。参考模型的结果作为支持或反对依据，分数只写在依据正文。新闻、公告、政策使用可扩展的依据类型，未接入的分析明确列为缺口，不编造来源。规则版本固定为 `HOLDING_ADVICE_V1`，历史保留原版本。

## 数据与服务边界

- Java 保存本人报告、当时持仓快照、依据原文、模型与输入身份、实际生成时间和数据日期。浏览器只访问 Java；每次读取、翻页、报告详情和生成都校验本人归属。读取用 `PORTFOLIO_SELF_READ`，手动生成用 `SIM_PORTFOLIO_SELF_WRITE`。
- Python 继续提供公共实验推理，新增只读的 20 交易日实际回报核验接口，不接收用户身份、金额、份额，不调用新的外部数据源。
- 新增报告与核验表通过 Java Flyway 管理，报告不可更新。核验状态和结果另存，已完成的核验固定保存当次来源版本与核验时间。
- 每日北京时间 08:30 起，独立后台每 30 分钟检查；网页关闭仍生成。当天相同输入与持仓不重复写入，输入或状态变化时追加版本。失败、不适用、未确认份额也保留具体状态。停机期间不伪造历史报告。
- 相同用户、基金、数据截止日、主模型、两套模型分数和建议规则的首次有效报告作为回看样本；同步水位变化及周末沿用仍可按日查看，但引用首次样本，不重复计数。模型实际分数变化另留新样本与当时观察区间。

## 回看口径

记录的是「当时的持有 / 卖出建议」。观察起点使用建议实际生成后的首个可按模拟规则操作的交易日（15:00 后顺延），终点为之后第 20 个交易日，不把生成前的涨跌算入建议效果。沿用报告继承原样本观察区间。

到期且 21 个交易日的单位净值与现金分红资料齐全后，计算现金分红再投资回报；缺失、未核验、来源失败、日历不足均保留待核验原因，不补造净值。核验由后台完成，历史清仓记录仍核验。正回报支持继续持有，负回报支持卖出，零回报单列持平。该比较不计申赎费、资金机会成本，展示「后续表现支持 / 不支持 / 持平」，不标成实际盈利或模型概率命中率。

效果回看展示独立样本数、已核验数、支持数、不支持数、持平数及待核验数，重复沿用与无建议记录另列。不同模型和规则不混算。当前每日 20 交易日区间有重叠，统计只作回看。

## 接口与验收

- `GET /api/v1/sim-portfolios/current/advice`：当前用户各基金最新报告摘要，一次批量读取。
- `GET /api/v1/sim-portfolios/current/advice/{fundCode}`：分页历史（日期筛选）与样本统计。
- `GET /api/v1/sim-portfolios/current/advice/{fundCode}/reports/{id}`：本人原始报告及独立核验结果。
- `POST /api/v1/sim-portfolios/current/advice/{fundCode}/generate`：生成当前时点报告，重试不覆盖历史。
- `GET /internal/v1/portfolio-advice/{fundCode}/outcome?startDate=...&endDate=...`：固定 20 交易日公共回报，只接受内部服务鉴权。

验证：持有/卖出/相反依据/不可用分支；同日幂等与跨日沿用；跨用户拒绝；日报原文不可覆盖；分页筛选；观察起点与节假日；分红再投、缺失数据与零回报；后台去重与清仓后核验；前端类型、构建、lint 与真实页面状态。测试数据使用独立临时用户并回滚或定向清理，真实服务验收与测试替身结果分开记录。
