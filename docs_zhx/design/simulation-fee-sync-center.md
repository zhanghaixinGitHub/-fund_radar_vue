# 模拟费率同步归入数据同步中心

2026-09-21。费率维护页仅保留规则查询和编辑；抓取、初始化统一进入数据同步中心。

## 页面与范围

- 数据同步左侧新增“模拟费率同步”，提供基金代码、单只刷新、全量初始化及任务进度。标签与输入框同一行。
- 单只刷新仅处理输入的六位基金代码。全量沿用原有范围：Java `sim_position` 与 `sim_plan` 去重后的基金代码，不扩大到全市场。
- 一键同步仅在任务总览展示，按标普500、完整资料、免费数据补齐、净值增量、特征快照、模拟费率的顺序执行六项。

## 接口和服务边界

- 浏览器创建 `POST /api/v1/sync-jobs/simulation-fees?fundCode=008888`；省略参数表示全量。返回 202 和既有 `SyncJobStatus`。
- `GET /api/v1/sync-jobs/simulation-fees/latest` 读取最近单只或全量任务；任务类型 `SIMULATION_FEES`，与市场同步共用 Python 单后台执行器及互斥。
- Java 创建接口及一键同步同时校验 `SYNC_JOB_START` 和 `SIM_FEE_RULE_ADMIN`；只读状态校验 `SYNC_JOB_READ`，不扩大任何角色权限。
- Python 从 Java `GET /internal/v1/simulation/fee-sync/fund-codes` 获取代码；最多四只并发抓取现有天天基金解析器，再逐只 `POST /internal/v1/simulation/fee-sync/profiles` 回写完整公共档案。Python 不访问 Java 数据库，不接收用户身份、持仓金额或订单。
- 回写地址仅来自 Python 服务端配置 `CORE_SERVICE_BASE_URL`，默认本机 `http://127.0.0.1:8080`；认证复用受保护的 `AI_SERVICE_TOKEN`。Java 拒绝无令牌、错误令牌、空配置和带浏览器来源标识的请求。
- Java 校验代码、来源、比例范围与连续天数分档，旧规则终止和新规则写入同事务提交。解析失败不发起回写，写入失败回滚；POST 超时不自动重发。
- 原费率维护页的 `refresh/{code}`、`init-all` HTTP 入口移除，避免绕过任务互斥；查询和编辑接口不变。

### 费率规则搜索（2026-09-21）

- 查询区复用基金市场的 `search-panel` / `search-row` 样式：上方“基金代码或名称”，下方长输入框和“查询基金”按钮，支持回车提交。
- 规则列表 `GET /api/v1/admin/sim-fee-rules` 新增可选 `keyword`，首尾去空格、最多 50 字符；按已存规则的代码或名称包含匹配，名称不区分大小写，空关键词显示全部。原 `fundCode` 精确过滤兼容保留，同时传入时取交集。
- 查询、COUNT 和分页使用同一筛选条件；提交关键词回到第一页，后续翻页保留已提交的关键词，无匹配时显示查询空结果提示。此查询不发起抓取，权限仍为 `SIM_FEE_RULE_ADMIN`。
- 验证：前端 lint、类型检查和构建通过；浏览器以本地接口替身确认代码/名称搜索、回车、分页、无匹配提示和清空恢复全部。Java 搜索契约新增 4 项通过，连同原相关单测共 19 项通过，未连接真实数据库。Java 需重新加载后使用新关键词筛选。

## 进度与失败

- 费率子任务进度按实际处理基金数累计，成功数仅统计 Java 已确认保存的基金。单只失败继续其余基金；返回成功、部分成功或失败及失败基金原因。
- 一键同步每项均尝试一次，费率未完整完成会进入整批未完成摘要。
- 页面关闭、刷新不影响后台运行；沿用现有本机任务管理器，Python 进程重启后实时任务状态清空，不宣称跨重启恢复或自动续跑。
- 本次不调整费率数值算法、金额分档、历史重算口径或人工费率被再次抓取替换的既有行为。

## 验收重点

1. 规则页不再出现抓取输入框和初始化按钮，查询和编辑仍可用。
2. 同步中心出现第六类任务，单只参数与全量范围正确，刷新能恢复状态且不再次 POST。
3. 整批进行中不能单独发起费率；单独费率进行中不能创建整批。
4. 解析失败、回写超时、全部失败、部分成功、空范围均如实显示；不得将失败计入保存成功。
5. Java 公共入口权限和内部回写服务认证均有拒绝用例；测试使用替身，不触发真实全市场同步。
