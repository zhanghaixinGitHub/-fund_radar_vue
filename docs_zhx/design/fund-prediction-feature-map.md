## 1. 核心判断

现有基准模型的信息维度确实偏窄，值得扩展；但不能据此认定“特征少”就是预测不准的主要原因，更不能认为加得越多越准。

2026-09-10 源码核对时，基准七项输入为：

| 特征字段 | 含义 |
| --- | --- |
| `return_5d` | 5 日收益 |
| `return_20d` | 20 日收益 |
| `return_60d` | 60 日收益 |
| `volatility_20d` | 20 日波动 |
| `max_drawdown_60d` | 60 日最大回撤 |
| `relative_position_60d` | 60 日相对位置 |
| `consecutive_decline_days` | 连续下跌天数 |

定义见 Python 仓库的 [historical_nav_evaluation.py](C:/pythonProject/workSpace06/app/services/historical_nav_evaluation.py:40) 中 `FEATURE_NAMES`。这是基准特征清单，不代表所有历史实验都只用过这些输入；项目此前已有市场指标等对照实验，具体结果以对应专项记录为准。

这些特征主要来自基金历史净值，能告诉模型“基金最近怎么走”，但没有充分告诉模型：

- 它到底持有什么资产？
- 这些资产的盈利、估值和经营情况正在怎样变化？
- 资金正在进入还是退出相关市场？
- 利率、政策、汇率和市场预期发生了什么变化？

值得扩展的是新的信息维度，而不只是把七个输入变成几十个相似技术指标。下文列出的都是候选特征及研究逻辑，不代表已经证明能提高本项目准确率。有些数据可公开取得，有些需要授权，有些只能近似估计；完整候选范围不意味着能统一、实时、完整地获取。

## 2. 预测基金，实际上是在预测什么

基金背后是一组资产。同样叫基金，收益来源可能完全不同。

| 基金类型 | 需要重点研究的对象 | 优先考虑的数据 |
| --- | --- | --- |
| 宽基指数基金 | 跟踪指数及其成分股 | 指数趋势、市场广度、整体估值、盈利变化、资金和宏观环境 |
| 行业主题基金 | 特定行业及产业链 | 行业景气、产品价格、订单、库存、政策、龙头企业盈利 |
| 主动股票／混合基金 | 持仓资产、仓位和经理行为 | 持仓变化、行业配置、风格、选股表现、资金申赎 |
| 债券基金 | 债券组合 | 利率曲线、久期、信用利差、评级、流动性、杠杆 |
| 货币基金 | 短期现金类资产 | 短期利率、存单收益率、期限结构、资产到期和流动性 |
| QDII 基金 | 海外底层资产，同时考虑汇率 | 对应市场数据、当地经济政策、币种及汇率对冲、交易时差 |
| 黄金／商品基金 | 实际持有的现货、期货或相关基金 | 商品价格、库存、供需、美元、实际利率、期货期限结构 |
| REITs | 基础设施项目经营和融资 | 出租率、租金、客流／车流、经营现金流、分派、负债成本 |
| FOF | 所持基金及其穿透后的资产 | 子基金配置、底层资产重叠、风格集中、费用和流动性 |

QDII 是跨境投资属性，仍需进一步区分股票、债券、商品等；ETF 也是产品形式，不能直接代表底层资产类别。

例如，债券基金的主要风险包括利率、信用和提前偿付风险，因此其特征体系与股票基金会明显不同。[Investor.gov：债券基金](https://www.investor.gov/introduction-investing/investing-basics/glossary/bond-funds-and-income-funds)

完整特征体系的第一步，应当是建立“基金 → 底层资产 → 影响因素”的关联。

## 3. 基金自身的数据

这部分回答：这是什么基金，它最近怎样运行，资产结构有没有变化。

| 数据类别 | 可以收集的数据 | 可以构造的特征 |
| --- | --- | --- |
| 产品属性 | 基金类型、主动／被动、跟踪指数、投资范围、成立日期、币种、份额类别 | 基金年龄、资产类别、行业／国家／币种标签、策略分类 |
| 净值与收益 | 单位净值、分红、拆分、复权收益序列 | 多周期收益、趋势斜率、短期反转、收益加速度、相对基准收益 |
| 波动与尾部风险 | 历史日收益、极端涨跌、回撤过程 | 下行波动、最大回撤、回撤持续时间、恢复速度、极端损失频率 |
| 资产配置 | 股票、债券、现金、衍生品、境外资产占比 | 股票仓位、现金比例、杠杆、资产配置变化 |
| 持仓结构 | 股票／债券名单、权重、行业、国家、币种 | 前十大集中度、行业集中度、单一发行人暴露、海外收入暴露 |
| 持仓变化 | 不同报告期持仓、新进、退出、增减仓 | 行业轮动幅度、持仓稳定性、换手特征、风格漂移 |
| 规模与份额 | 基金资产规模、份额、申购赎回、持有人结构 | 份额增长率、净流入率、大额赎回压力、机构持有集中度 |
| 费用与运行 | 管理费、托管费、交易成本、申赎限制、跟踪误差 | 费用拖累、跟踪偏离、现金拖累、流动性约束 |
| 基金经理及团队 | 任职变更、任职年限、管理规模、同期管理产品 | 任职时长、管理负担、历史风格稳定性、调整市场和风格影响后的历史表现 |
| 同类比较 | 同类基金收益、风险、资金和持仓 | 同类收益分位、相对强弱、同类资金偏好、拥挤程度 |

三个容易误解的地方：

- **净值高不等于估值贵。** 一只基金净值从 1 元变成 3 元，不能直接推导出它比净值 1 元的基金贵。
- **规模增加不等于资金流入。** 资产上涨也会让规模增加，需要区分价格变动和申购赎回。
- **持仓报告不是实时持仓。** 例如 Tushare 的基金持仓接口说明为季度更新，并区分公告日期和截止日期；历史模型必须按当时已经公开的资料使用。[Tushare：基金持仓](https://tushare.pro/document/2?doc_id=121)

## 4. 底层股票、债券和行业数据

对于股票基金，基金净值只是持仓资产变化的汇总结果。深入到被投企业，才有机会补充新的信息。

| 数据类别 | 原始数据举例 | 可以构造的特征及用途 |
| --- | --- | --- |
| 股票估值 | PE、PB、盈利收益率、股息率、自由现金流收益率 | 持仓估值水平、历史估值分位、相对同行估值差 |
| 企业盈利 | 营收、利润、每股收益、毛利率、净利率 | 持仓加权盈利增长、盈利加速／减速、利润率变化 |
| 财务质量 | 经营现金流、应收账款、存货、负债、利息支出 | 现金流与利润匹配度、偿债压力、存货积压、盈利质量 |
| 市场预期 | 分析师盈利预测、预测修订、业绩指引、实际业绩 | 盈利预测上调比例、预期分歧、业绩超预期程度 |
| 企业经营 | 订单、销量、产量、产能利用率、用户数、客单价 | 需求变化、经营拐点、增长持续性 |
| 股东和公司行为 | 回购、增减持、解禁、质押、增发、并购 | 潜在供给压力、回购强度、融资压力、事件暴露 |
| 行业景气 | 行业销量、库存、开工率、资本开支、价格 | 行业景气变化、库存周期、供需缺口 |
| 产业链关系 | 原材料价格、供应商、客户、上下游收入关联 | 成本冲击、利润传导、客户需求变化 |
| 债券信用 | 评级、评级展望、发行人财务、违约及展期事件 | 信用恶化暴露、评级下调比例、信用集中度 |
| 债券利率敏感性 | 久期、凸性、到期收益率、期限、票息 | 对利率变化的敏感度、期限风险、票息收益支撑 |

价值、质量、动量、规模、低波动等，也是成熟因子研究中的常见维度。不过，长期因子研究不能直接证明它们能提高未来 20 天的涨跌准确率。[MSCI：因子体系](https://www.msci.com/indexes/factor-indexes/msci-factor-indexes)

行业数据尤其需要具体到业务：

| 行业方向 | 可以继续深入的数据 |
| --- | --- |
| 半导体 | 芯片销售、存储价格、库存、晶圆厂利用率、设备订单、资本开支、出口限制 |
| 食品饮料 | 批发价格、渠道库存、销量、终端消费、促销强度、原材料成本 |
| 新能源车 | 销量、订单、折扣、电池装机、锂价、库存、出口 |
| 光伏 | 硅料／硅片／组件价格、排产、库存、装机量、产能投放 |
| 医药 | 临床试验结果、审批、集采、医保政策、专利到期、产品销售 |
| 银行 | 净息差、不良率、拨备、贷款增长、存款成本、地产相关风险 |
| 煤炭／有色 | 现货价格、库存、产量、开工率、进口、下游需求 |
| 军工 | 已公开订单、交付、预算、应收及回款、产业链产能 |

这些数据不必叫“基金数据”。只要能通过持仓或投资范围关联到基金，就可以进入候选范围。

但企业经营变好，并不自动意味着短期股价上涨，市场可能早已预期到。因而，“变化是否超出此前预期”通常比只记录“好／坏”更值得研究。

## 5. 市场交易、资金和情绪数据

这部分补充市场正在怎样反应。

| 数据类别 | 原始数据举例 | 可以构造的特征 |
| --- | --- | --- |
| 对应基准行情 | 实际跟踪指数、行业指数、风格指数 | 基准趋势、基金相对强弱、相关性、跟踪偏离 |
| 市场广度 | 上涨／下跌股票数、创新高／低数量、均线上方股票比例 | 上涨参与度、趋势扩散程度、市场内部恶化 |
| 风格轮动 | 大盘／小盘、价值／成长、红利／科技等指数 | 风格收益差、轮动速度、基金与当前强势风格的匹配度 |
| 成交与流动性 | 成交额、换手率、买卖价差、盘口深度 | 放量程度、流动性收缩、交易冲击、价格与成交背离 |
| ETF 份额与申赎 | 份额变化、申赎篮子、净申购赎回 | 行业资金流入、连续流入天数、流入相对规模 |
| 杠杆资金 | 融资余额、融资买入、融券、抵押融资情况 | 杠杆拥挤、融资扩张、潜在去杠杆压力 |
| 期货市场 | 基差、期限结构、持仓量、成交量 | 期现偏离、套保压力、期限结构变化 |
| 期权市场 | 隐含波动率、偏斜、期限结构、认沽认购交易 | 市场定价的波动与尾部风险、避险需求变化 |
| 持仓拥挤 | 机构共同持股、主题基金重叠、集中持有 | 拥挤程度、共同减仓风险、资产相关性上升 |
| ETF／LOF 场内价格 | 市场价格、净值、参考净值 | 折溢价、折溢价历史分位、异常交易偏离 |

ETF 的场内价格与净值可能不同，折溢价和买卖价差因此是独立的研究维度；预测净值收益与预测场内成交收益也应分开。[Investor.gov：ETF 价格与净值](https://www.investor.gov/introduction-investing/general-resources/news-alerts/alerts-bulletins/investor-bulletins-24)

这类数据的边界：

- 网站上的“主力净流入”往往依赖成交分类算法，不能直接当成机构真实净买入。
- ETF 成交活跃不等于份额净申购，两者要分开。
- 期权隐含指标包含风险溢价，不能直接翻译成真实上涨概率。
- 一些成交信号变化很快，可能适合日内或数日研究，对未来一个月未必有增益。

## 6. 宏观、政策、海外和跨资产数据

| 数据类别 | 数据举例 | 可以构造的特征 |
| --- | --- | --- |
| 经济增长 | GDP、工业增加值、消费、投资、出口 | 增长变化、经济景气、实际值相对预期的偏差 |
| 景气调查 | PMI、新订单、就业、企业信心 | 景气改善／恶化、订单领先变化 |
| 通胀与成本 | CPI、PPI、工资、能源、运费 | 通胀压力、上下游价格差、利润挤压程度 |
| 货币与信用 | 社融、信贷、货币供应、财政收支 | 信用扩张变化、融资环境、政策力度 |
| 利率与流动性 | 政策利率、回购利率、存单利率、国债曲线 | 利率变动、长短利差、资金紧张程度 |
| 信用市场 | 不同评级信用利差、违约、发行及融资情况 | 风险偏好、信用压力、融资难度 |
| 汇率 | 人民币及持仓相关币种汇率、远期价格 | 汇率收益贡献、汇率波动、对冲成本变化 |
| 海外市场 | 对应国家指数、行业指数、海外龙头、当地利率 | 隔夜联动、相对表现、跨市场风险传导 |
| 商品市场 | 黄金、原油、铜、农产品及库存 | 通胀和需求线索、行业成本、商品基金驱动 |
| 政策及地缘事件 | 税收、补贴、监管、贸易限制、制裁、冲突 | 受影响持仓比例、事件强度、政策阶段和持续时间 |

例如：

- 对出口企业较多的基金，汇率和贸易政策可能值得重点研究。
- 对黄金相关基金，实际利率、美元及黄金供需可以进入候选范围。
- 对长久期债基，收益率曲线变化与组合久期的配合更直接。
- 对海外股票基金，必须按真实预测时点处理当地行情和时区。

宏观数据还有“历史版本”的问题。今天查到的某个月数据，可能已经修订，不能默认历史当时就知道这个数。圣路易斯联储的 ALFRED 专门保存历史发布版本，正是为解决这类问题。[ALFRED：历史版本说明](https://alfred.stlouisfed.org/help)

## 7. 新闻、文本和另类数据

| 数据类别 | 原始数据举例 | 可以构造的特征 |
| --- | --- | --- |
| 公司公告 | 财报、业绩预告、重大合同、诉讼、处罚 | 事件类别、金额相对公司规模、受影响持仓权重、事件距今时间 |
| 行业及政策新闻 | 产业政策、供需事件、技术突破、贸易限制 | 行业关联度、政策落地阶段、受益／受损业务暴露 |
| 业绩说明会及研报 | 管理层指引、问答、分析师观点 | 预期调整、经营措辞变化、观点分歧、不确定性 |
| 基金经理报告 | 对仓位、行业、估值和风险的描述 | 投资观点变化、风格变化、表述与实际持仓的一致性 |
| 媒体与社交情绪 | 新闻数量、搜索热度、讨论量、情绪 | 关注度异常、情绪变化、观点分歧、重复炒作程度 |
| 经营替代数据 | 合法取得的汇总销售、招聘、物流、应用使用、客流 | 对企业经营和行业需求的辅助估计 |
| 天气及自然环境 | 温度、降雨、灾害、干旱、水位 | 农业、能源、水电、物流等相关资产的风险暴露 |
| 技术及产业创新 | 专利、研发进展、产品发布、标准变化 | 技术进展、竞争格局变化、研发转化线索 |
| 日历与已知安排 | 财报预约、政策会议、指数调仓、解禁、期权到期 | 距事件天数、已知供给变化、事件密集度 |

新闻特征不应只有一句“大模型判断利好”。更有用的加工方式是：

> 发生了什么 → 关联哪些公司／行业 → 基金涉及多少 → 信息是不是新的 → 和原来预期差多少 → 市场已经反应多少。

例如，“半导体政策利好”可以拆成：

- 是讨论、征求意见，还是正式生效？
- 支持的是设备、材料、设计，还是制造？
- 基金实际涉及这些业务的比例是多少？
- 同一事件是否被十家媒体重复报道？
- 消息公布之前，相关资产是否已经明显上涨？

大模型可以帮助抽取这些字段，但它生成的乐观程度不等于经过验证的上涨概率。

## 8. 原始数据怎样变成模型特征

有了数据，还需要决定怎么表达。一个数据点通常可以转换成几类不同信息。

| 表达方式 | 例子 | 模型能看到什么 |
| --- | --- | --- |
| 当前水平 | 当前利率、库存、估值 | 现在处于什么状态 |
| 变化 | 利率变化、库存下降、盈利预测上调 | 正在往哪个方向变化 |
| 变化速度 | 盈利增速继续加快还是放缓 | 趋势是否在转折 |
| 历史位置 | 估值处于过去历史的哪个分位 | 相对自身是否异常 |
| 相对比较 | 行业收益减市场收益 | 强弱是否只是大盘带动 |
| 超出预期 | 实际业绩减此前市场预期 | 是否出现新信息 |
| 持仓加权 | 各持仓权重 × 对应企业指标 | 这件事与这只基金有多大关系 |
| 交互关系 | 行业暴露 × 行业冲击；久期 × 利率变化 | 同一外部变化对不同基金的不同影响 |
| 数据状态 | 披露距今时间、持仓覆盖率、缺失比例 | 输入是否过时、是否足够支持判断 |

持仓加权和交互关系特别值得重视。假设两只基金都看到“芯片行业订单改善”：第一只基金芯片相关暴露高，第二只主要持有银行和食品饮料，同一条新闻不应该给两只基金相同的输入影响。

可以构造这样的候选特征：

> 基金相关行业强弱 = 各已知行业权重 × 各行业相对市场收益，再求和。

如果只掌握覆盖 60% 资产的持仓，就只能称为“已知持仓部分的指标”，同时保留覆盖率，不能假装已经知道整只基金。

具体指标需要分别确定计算规则，不能把所有比率都机械地按持仓权重求平均。历史分位、归一化、行业分类和权重，也都只能使用预测时点之前可得的资料。

## 9. 面向未来 20 个交易日的研究优先级

下表是研究优先级判断，不是已经验证的有效性排名。

| 优先级 | 特征组 | 优先研究的原因 |
| --- | --- | --- |
| 第一批 | 实际基准、行业及风格暴露、底层资产映射 | 先让模型知道基金究竟受什么影响 |
| 第一批 | 对应市场趋势、行业相对强弱、市场广度、波动状态 | 提供基金净值之外的市场环境 |
| 第一批 | 与基金相关的资金申赎、流动性、利率或汇率变化 | 按基金类别补充直接相关的驱动 |
| 第二批 | 盈利预测修订、业绩超预期、行业经营变化 | 研究新增信息是否能改善未来数周判断 |
| 第二批 | 估值、拥挤程度、持仓变化、重要事件 | 补充市场状态和风险背景 |
| 第三批 | 新闻文本、社交情绪、细分经营和另类数据 | 信息潜力较大，但清洗、关联和历史验证难度更高 |

预测周期换了，顺序也要调整：

- **未来 1～5 天：** 交易、流动性、突发事件、隔夜市场反应更值得优先研究。
- **未来约一个月：** 行业趋势、盈利预期变化、资金、市场状态及政策事件值得研究。
- **未来半年到一年：** 估值、盈利质量、行业周期、资产配置和经理能力更值得重视。

这不是固定规律，需要用目标基金和对应周期验证。对于货币基金等产品，“是否上涨”本身区分度可能很低，预测收益水平或流动性风险可能更有意义。

## 10. 怎样验证新增数据是否真的提高准确率

### 10.1 增加的是新信息，还是同一信息的重复表达

从同一条净值曲线计算几十种技术指标，可以形成不同表达，但没有引入新的外部事实。

同样，已有基金收益和市场收益时，再加入“基金收益减市场收益”，也不是第三个独立信息来源；它的帮助取决于模型和表达方式。

### 10.2 区分解释过去与预测未来

持仓与当日净值高度相关，不代表能预测之后一个月。预测时点以后才公布的持仓、财报或行情，更不能放回历史输入。

预测目标必须明确：净值总收益、场内价格收益、超额收益、波动、回撤或风险事件不是同一个目标。分红、交易成本和预测时点应按对应目标统一处理。

### 10.3 不强行共用一种关系

同样的利率变化，对股票、长债、货币和黄金相关基金的影响机制不同。可以研究按类型分组、加入资产暴露交互项，或者建立共享模型加类型分支，而不是一开始就无限拆模型。

### 10.4 留出真正没用来挑特征的时间段

特征筛选、参数选择和反复看错题，都会消耗验证数据的独立性。应按时间滚动评价，并清除跨越训练和验证边界的未来收益标签。普通随机打乱不适合直接用于这类任务。[scikit-learn：时间序列划分](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.TimeSeriesSplit.html)

时间划分工具本身不会自动解决金融标签重叠、基金之间相关、历史数据修订等问题，仍需按真实标签区间和可得时间检查。不能将同一天的多只基金、同一基金相邻的 20 日标签视为完全独立样本。

### 10.5 按信息组比较，不只看总体准确率

可以比较：

> 基础输入 → 加行业组 → 加资金组 → 加盈利预期组 → 加事件组。

每组优先分别与同一基础输入比较，保留失败结果；组合实验另行登记，避免混淆各组的作用。比较应使用共同可评分样本，同时报告新增特征造成的缺失和覆盖变化。

同时看不同基金、不同时间段、上涨与非上涨的识别、概率是否可信，以及不确定时放弃判断的覆盖率。相关特征还需要联合检查，单项重要性可能误导。[scikit-learn：特征重要性与相关特征](https://scikit-learn.org/stable/modules/permutation_importance.html)

## 11. 建议的下一轮研究假设与产品边界

建议围绕一个明确假设设计下一轮：

> 在基金历史走势之外，加入“实际资产暴露＋对应行业／市场变化”，能否在未参与选特征的时段稳定减少错误？

先检验新的信息维度有没有价值，再决定是否继续加入盈利、资金和新闻数据。具体数据源、样本范围、模型、评价窗口和验收标准，需要在实际开展该轮研究时确定；本文件没有启动采集、训练、部署或模型发布。

个人买入成本、仓位、资金需求和风险承受能力，对“是否应该调整持仓”很重要，但通常不应作为预测基金市场涨跌的驱动。它们适合放在预测之后的个人决策层，让模型研究服务于持仓预警与决策辅助目标。

实际形成建议时，应继续区分事实、用户规则和模型推断，并说明来源与日期、基金关联、触发条件、反向证据和失效条件。数据不完整或模型证据不足时，保留未知和暂不判断。
