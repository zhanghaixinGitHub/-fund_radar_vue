## 判断边界

- 新版本`002112_EVENT_EVIDENCE_V2`不使用净值涨跌、公告条数、覆盖率、缺失标记或字符词频直接打分。净值仍保存并用于描述走势、波动及风险。资料覆盖率仅用于阻止资料不足时出结论。
- 方向输入限定为四项持仓/指数行情及四项具体事件信号。事件必须具备原文、摘要、可用时间和当时已披露持仓关联；方向未知、传闻、提案、泛行业关联和例行程序公告不转成利好/利空。业绩预告独立于已实现事项。
- 用公开日期计算交易日年龄，接收时间仅控制可用性。初始保守规则：5个交易日内参与，2个交易日半衰期；同一公司/类别/方向只取最强事件，不随公告或转载数量累加。这些是预先固定的研究规则，不宣称最优。
- 8项输入采用无截距、非负系数的逻辑回归，防止下跌、负面事件反向加上涨分。仅使用原冻结样本，按原季度前推划分进行14次对照拟合，再拟合晨晚2个最终包；独立目录和账本，上限16次，无参数搜索、不重跑旧模型。
- 无合格事件、事件冲突（较弱一侧达到较强一侧35%）、事件与持仓行情相反、缺少同方向事件作用、比较分数不足0.60、行情覆盖不足50%或事件超限时，分支保存`ABSTAINED`，方向/分数/类别分数为空，附具体原因。暂不判断不等于持平，不进入方向命中率分母。
- 只报告同日期的旧新比较、输出方向覆盖率和暂不判断数量，不能通过丢掉难例伪称准确率提高；当前结果属于历史研究，仍需未来验证。
