# 基金雷达待选样式与交互方案（未启用）

版本：2026-11-13。适用范围：前台、后台、登录注册、新增页面及所有弹窗、抽屉、表单和状态。

## 依据与边界

以当前“资产总览”可点击方案为视觉方向，吸收用户逐项确认：灰绿侧栏加深、页内菜单白底文字、选中加粗配绿色下划线（最新偏好）、单行横向滚动、点击抽屉外关闭、左侧固定而右侧独立滚动。预览不是正式功能实现；不得把示例数据和空状态替换成正式业务结果。

本文件仅保存本轮拟议方案，不是当前开发的强制规则。用户已于2026-11-13决定暂停改版，保持现有页面；所有下文的“必须”等要求仅在以后明确采用本方案后生效。业务范围见 [功能保全清单](frontend-redesign-functional-baseline-2026-11-13.md)。业务权限、计算、数据来源和运行授权保持原样。下面未获单独确认的尺寸属于实施基准，可在保持整体一致的前提下微调。

## 布局与导航

- 桌面主框架为固定左侧导航 + 右侧工作区；前台六个入口依次为基金市场、基金经理、我的关注、我的持仓、持仓分析、站内提醒。后台为工作台、数据同步、用户管理、费率维护。个人信息在账户区，前后台按权限切换。
- 左侧不展开长子菜单，不因右侧页面切换而跳动。不把全部基金资料栏目塞进左侧。
- 桌面框架占满可见高度（100dvh）；页面本身不滚动，右侧工作区独立滚动。左栏不跟随右侧上下移动；极矮窗口允许左栏独立滚动，不隐藏入口。不得用固定最小高度撑出页面滚动。
- 左栏建议宽度194–224px，内容区 min-width:0；正文左右留白24–38px。窄屏使用可打开的导航抽屉，不能直接移除入口。
- 页内菜单一行显示、不换行，白底文字；普通项正常字重，选中项加粗、绿色文字与底部绿色下划线。不采用整条浅绿底或深绿实心选中块（2026-11-13用户图二偏好，覆盖此前底色方案）；溢出时横向滚动，保留滚动条，支持鼠标滚轮与触控板。点击靠后的栏目保持可见，不能跳回开头。仅鼠标在溢出菜单上时把纵向滚轮转换成横向；没有溢出或到边界后应允许正常页面滚动。
- 账户前五个栏目固定为总览、持仓、收益明细、交易记录、定投计划；其余三个放在账户管理入口，入口与内容都保留。此为新布局顺序，旧路由参数仍须兼容。
- 详情支持直达和刷新；返回列表保留关键词、类型、评级、页码及每页条数等原有条件。保留经理来源链和历史消息链接；浏览器前进后退可用。

## 颜色

所有颜色通过公共变量使用，禁止每页自行指定一套色值。绿色同时用于品牌与选中状态，不能把上涨和选中混为一谈。

| 用途 | 建议变量 | 色值 |
|---|---|---|
| 页面背景 | --color-canvas | #F1F4EF |
| 内容表面 | --color-surface | #FFFFFF |
| 左栏背景 | --color-sidebar | #E4EBE1 |
| 左栏选中 | --color-sidebar-active | #BDD1BB |
| 页内菜单底色 | --color-tabs | #FFFFFF |
| 品牌、主按钮、页签选中 | --color-primary | #38745D |
| 主文字 | --color-text | #263D33 |
| 次要文字 | --color-text-secondary | #526757 |
| 边框 | --color-border | #D8E2D3 |
| 抽屉背景 | --color-drawer | #FCFDF9 |
| 弹窗背景 / 标题栏 | --color-dialog / --color-dialog-header | #FFFEFB / #EDF2E8 |
| 上涨、正收益 | --color-rise | #B84C43 |
| 下跌、负收益 | --color-fall | #287B60 |
| 持平 | --color-flat | #64756A |
| 警告背景 / 文字 | --color-warning-bg / --color-warning | #F5EFDF / #80632D |
| 危险操作 | --color-danger | #A84940 |

红涨绿跌，必须带正负号和数值，不能只依赖颜色。删除、失败等状态有文字或图标辅助。普通正文对比度至少4.5:1，大字至少3:1；禁用态不能被误认为可点击。市场数值与收益按原口径显示，缺失为“—”，不能用0代替。

## 字体、间距与组件

- 中文优先 Microsoft YaHei、PingFang SC、sans-serif；正文14px，辅助12px，页内菜单14px，普通400–500、选中600–700，页面标题26–30px/700，区块标题18–20px/600。同类金额等宽数字，表格数值右对齐。
- 间距以4px为基础，常用8/12/16/24/32px；区块间距24px，相关控件8–12px。按钮圆角7px，页签6px，内容区域12px，弹窗14px。避免多层卡片包裹。
- 主按钮深绿白字，次按钮白底绿字细边框，普通查看为文字按钮。页内菜单采用文字与下划线，不套用主按钮的实心选中样式。单个操作区只强调一个主要动作；危险操作单独使用危险色。
- 桌面按钮和输入框建议高度38–40px，触屏至少44px；悬停、按下、键盘焦点、禁用、处理中均有明确状态。提交中防重复点击，不凭前端提示假装成功。
- 筛选：业务标签始终可见；关键词、类型、评级、状态等遵循同一排版。查询/重置位置固定。修改筛选回到第一页，返回详情不丢条件。
- 表格：表头浅灰绿、细分隔线、稳定列宽；长名称合理换行，宽表仅在自己的容器横滚。金额和百分比不混列；空、加载、错误和无权限不能共用一个“暂无”。
- 分页：总数、当前页、上一页/下一页和每页条数统一；边界禁用，不能生成空的下一页。不改变已有分页和数据范围口径。
- 图表：同一涨跌含义、日期格式和数字精度；标明单位、日期范围与提示，缺失区间不画成真实连续结果；保留已有周期和日期筛选。

## 页面、抽屉与弹窗如何选

| 场景 | 载体与行为 |
|---|---|
| 基金/用户快速查看 | 右侧抽屉，保留列表现场；完整资料入口进入详情页 |
| 多栏目长资料、历史、收益、分析 | 完整页面或页内栏目，保持可分享地址 |
| 买入、卖出、定投设置、积分发放、密码重置 | 聚焦表单弹窗；字段、校验、预览和确认全部保留 |
| 简短危险操作 | 明确对象、影响的确认框，不能用模糊“确定吗” |
| 字段解释 | 提示或小型浮层，不用大弹窗打断阅读 |

- 当前资产总览速览：点击右侧框外的页面区域收起；该次点击仅关闭，不触发底下操作。框内点击不关闭。关闭按钮和Esc同样可用；筛选、页码、滚动位置保留。
- 表单弹窗打开时，外部点击关闭速览的规则不得抢先触发；有未保存修改或正在提交时不得静默丢失输入。普通速览无编辑可直接收起。
- 弹窗管理焦点，Tab不跑到背景，关闭回到触发按钮；标题可供读屏识别。预览层级建议导航10、抽屉30、遮罩40、弹窗50、通知100；共用层级规则，不能互相遮住。
- 错误保留输入并给出重试方式；成功显示服务端确认结果。刷新不能重复提交订单、规则或后台任务。

## 文案、权限与数据

遵守AGENTS.md的基金信息优先规则。用户页不展示模型、接口、调试和训练过程；后台现有专用诊断能力仍按原权限保留。角色和权限决定入口可见性，不能靠隐藏按钮代替服务端鉴权。

现有每日任务与独立收益更新授权保持不变。改版不得启用旧自动训练、自动定投、结算或清理任务；模拟买卖必须继续明确标为模拟。日期使用北京时间，预测期数、资料日期、风险提示和未完成原因保留。

## 新功能必须遵守

1. 先把新能力写入功能清单，确定前台/后台、权限、入口、读取/写入、详情返回方式及验收条件。
2. 复用公共变量与组件，不复制页面独立皮肤；先判断完整页、抽屉、弹窗还是字段提示。
3. 提供真实、加载、无结果、错误、过期、无权限、处理中等适用状态；不得编造分析、收益或资料。
4. 同时检查1440、1280、平板和手机宽度，以及矮窗口；允许表格/菜单局部横滚，不能整个页面横向撑破。
5. 核对鼠标、键盘、触屏和读屏；核对返回条件保留、确认防重、关闭行为及角色隔离。
6. 对照功能保全清单登记证据。新增功能、入口变化或口径变化需同步更新本规范和清单，不能只改效果图。

## 改版验收门槛

功能清单每项必须填写新位置、实现状态、权限、验证证据。未验证保持“待验收”，不允许因为入口变好看就标记完成。旧功能移除、合并造成行为变化必须获得用户明确同意。预览不调用业务接口的限制只适用于预览，正式改版仍须连接真实服务并验证原有行为。
