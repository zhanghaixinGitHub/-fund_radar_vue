## 2. 管理员真实小范围冒烟（部署后手工执行）

真实同步不属于部署动作。管理员选择空闲时段，在同步中心点击“当前 2000 积分免费数据补齐”前，按以下顺序执行；任何一步失败都不继续扩大范围。

| 编号 | 操作 | 预期 | 证据 |
| --- | --- | --- | --- |
| TDC-M01 | 检查 `source_registry` 能力清单 | 仅包含已验权 13 个接口；不包含 `fund_portfolio`、新闻、公告 | 只读 SQL 结果 |
| TDC-M02 | 选择 1 只已有明确 `.SH`/`.SZ` 来源代码的场内基金、1 条已登记 `DRAFT` 指数、最小日期窗口 | 不猜测交易代码或基准代码 | 管理员登记记录 |
| TDC-M03 | 启动补齐任务并观察任务卡 | 单任务运行；显示父运行 ID、阶段和真实计数 | 同步中心截图与运行记录 |
| TDC-M04 | 重跑相同窗口 | 无重复业务键；相同行计入 `skipped_count` | 表键查询与运行统计 |
| TDC-M05 | 模拟或选择一个无数据日期 | 非交易日/无披露不补零；对应游标不被误推进 | 游标和运行记录 |
| TDC-M06 | 打开基金详情、关注详情、预测页 | 只读本地数据；没有外部 Tushare 请求 | 服务日志与浏览器网络记录 |

## 3. 失败与回归

| 编号 | 场景 | 预期处理 |
| --- | --- | --- |
| TDC-R01 | 来源能力缺失、Token 配置缺失或权限被收回 | 任务失败，返回脱敏提示；不发起未登记接口调用，不推进游标 |
| TDC-R02 | 同步任务正在运行时再次点击 | 返回 409/“已有同步正在执行”；不创建第二个任务 |
| TDC-R03 | 单个基金或指数响应代码不一致、字段不完整或达到行上限 | 该数据域失败，已成功数据保留，失败实体游标不推进 |
| TDC-R04 | Python 重启后读取最近任务 | 进程内最近任务可为空；持久化“上次成功时间”仍可读取 |
| TDC-R05 | 普通用户调用启动接口 | Java 服务端拒绝；前端隐藏/禁用不作为授权依据 |

## 4. 验收结论边界

通过本用例只能证明“已实现、可迁移、链路可调用、不会自动拉取”。在管理员完成 TDC-M01 至 TDC-M06 前，不能宣称全量免费数据已回补，也不能据此输出基金收益预测或持仓结论。
