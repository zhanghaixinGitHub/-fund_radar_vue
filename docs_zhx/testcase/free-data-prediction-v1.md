## TC-FDP-01｜手算一条 20 日标签

前置条件：选择一只股票型基金和一个历史截止点；该截止点及其后至少有 20 条有效净值，起点/终点净值都有公告日。

操作步骤：

1. 记录起点净值的业务日期、公告日和统一净值口径。
2. 找到该基金之后第 20 条有效净值，记录其业务日期与净值。
3. 按 `终点净值 / 起点净值 - 1` 手算未来收益。
4. 收益大于 0 标为 `1`，否则标为 `0`。

数据库验证：

```sql
SELECT fund_code, nav_date, ann_date, unit_nav, accumulated_nav, adjusted_nav
FROM nav_daily
WHERE fund_code = :fund_code
  AND nav_date BETWEEN :start_nav_date AND :end_nav_date
ORDER BY nav_date;
```

| 验收点 | 预期结果 |
| --- | --- |
| 窗口 | 第 20 个终点按同一基金的有效净值顺序计算，不按自然日猜测。 |
| 口径 | 起点与终点使用同一净值口径；不可混合单位、累计和复权净值。 |
| 标签 | 与手工计算出的上涨/非上涨结论一致。 |

## TC-FDP-02｜公告日晚于截止日时不得进入特征

前置条件：准备一条净值业务日期早于公告日期的数据。

操作步骤：

1. 将特征截止时间设为公告日前一天。
2. 构建该时点特征快照。
3. 将截止时间推进到公告日，再次构建。

| 验收点 | 预期结果 |
| --- | --- |
| 公告日前 | 该条净值不在特征输入中。 |
| 公告日及之后 | 该条净值才可成为输入。 |
| 可追溯性 | 快照能记录业务日期、`available_at` 和来源运行。 |
| 降级 | 缺少公告日时，该点不用于 V1.0 训练/评分。 |

## TC-FDP-04｜规则基线与逻辑回归都必须参加同一场回测

前置条件：已生成多个历史日期的股票型训练样本，并固定训练、验证、独立测试区间。

操作步骤：

1. 在训练期分别运行永远上涨、历史上涨频率、趋势延续、固定公式和逻辑回归。
2. 只使用验证期选择候选模型配置。
3. 锁定配置后读取独立测试期结果。

| 验收点 | 预期结果 |
| --- | --- |
| 公平比较 | 所有方法使用同一批样本、相同截止日和相同标签。 |
| 结果 | 同时输出方向准确率、Brier 分数、覆盖率和按基金/市场阶段分组结果。 |
| 结论 | 逻辑回归没有稳定增益时，不进入发布候选。 |
