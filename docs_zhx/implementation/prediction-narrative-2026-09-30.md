# 预测依据统一表达（2026-09-30）

## 用户可见变化

走势预测和预测历史共用 `PredictionEvidenceBody`。依据按“结论、历史表现、主要依据、相反因素、需要留意”组织；缺少相反因素时不编造该段。保留原预测日期、周期与必要局限，不增加专业术语释义，不在日常页面展示模型、接口或处理参数。

DeepSeek 只整理原预测已经核对的事实。预测方向、指标、数值、日期和局限由程序提供；输出中的事实占位符由程序替换。正文不能改变原判断，也不能把指标贡献解释成真实市场涨跌原因。原记录无法恢复、生成失败或内容校验不通过时，继续显示已有依据。

本次进一步升级为 V3：每项依据补充“当前值与历史参考的差异、原判断采用的作用关系、单独换回参考水平后的结论”。参考值和关系来自当时保存的参数，对照保持其他输入不变，并沿用原分类与并列规则；不读取新行情、不重训、不保存新的预测。支持项与相反项逐项成段；历史参考不冒充该基金自身均值，对照结果不冒充真实市场情景或历史相似情况的发生频率。

## 调用与权限

| 页面调用（POST，无正文） | Java 校验 | Python 内部调用（POST） |
| --- | --- | --- |
| `/api/v1/watchlist/{fundCode}/prediction-1d/evidence/{forecastId}/narrative` | 登录、关注范围、本人档案关联；从档案取得作业编号与原文摘要，并核对返回身份 | `/forecast-jobs/{job_id}/narrative?fund_code=...`，沿用一日预测路由前缀 |
| `/api/v1/watchlist/{fundCode}/predictions/{predictionId}/narrative` | 登录、关注范围、返回基金与记录编号 | `/funds/{fund_code}/predictions/{prediction_id}/narrative`，沿用多周期路由前缀 |

沿用现有浏览器会话及 CSRF、内部 `X-Service-Token` 和 Origin 限制。浏览器不能提交事实或提示词。返回包含 `fundCode/kind/recordId/state`，成功时包含 `narrative`；前端再次核对基金、类型及记录，切换页面时丢弃迟到响应。

Python 从原作业结果或原 LIVE/PRIMARY 多周期记录恢复内容，核对原文摘要。每日依据继续使用已有解释恢复流程；多周期仅支持已能复算的三种现有适配方式。分支方向或同一指标作用方向存在分歧、原参数缺失、复算结论不一致时，不生成新说明。旧二分类记录不改写为三分类结论。

## 风格与内容约束

- 固定提示词、低随机性、JSON 结构和统一长度要求；编辑输出为 context 字符串与 supporting/opposing 字符串数组，保存及返回时仍使用原来的三个字符串字段，逐项段落以换行分隔。Java 透传契约不变。
- 每项观测、关系、对照由程序核对并锁定，DeepSeek 负责串联。每组引用必须按顺序出现一次，不得跨指标调换关系或对照；不允许自由填写数值、方向或市场原因。
- 校验空输出、截断、字段、引用、篇幅、已知不当措辞与明显方向矛盾。程序校验和提示词不能证明全部自然语言语义始终正确，后续调整仍需评估不同方向及冲突样例。
- 同一解释版本成功后直接复用，避免刷新、切换页面或改用另一模型后文字发生变化。此次明确升级才生成 V3，旧版原文保留；新版失败继续显示旧版，新版并发生成时页面可保留旧版并有限等待。

请求关闭思考模式，使用 `temperature=0.2`、JSON 输出、最大 1800 tokens。单次调用不自动重试；限制响应大小和读取耗时。API 依据：[请求参数](https://api-docs.deepseek.com/api/create-chat-completion/)、[思考模式](https://api-docs.deepseek.com/guides/thinking_mode/)、[JSON 输出](https://api-docs.deepseek.com/guides/json_mode/)。

Alembic `20260930_32` 创建解释表，`20260930_33` 将唯一键升级为原类型、原记录编号、解释版本三项，均已在本地库执行；部署其他环境需先执行既有迁移流程。`prediction_narrative` 保存事实摘要、解释版本、正文摘要、状态及租约。此次迁移原样保留旧行，成功记录继续由数据库触发器保护，不允许覆盖或删除。

生成时短事务领取租约，外部调用在事务外执行。全服务最多两个在途请求，租约 90 秒；同一原预测、同一解释版本最多三次尝试，失败冷却 15 分钟。版本由服务端发布固定，客户端不能指定版本绕过预算；跨版本仍核对基金与原预测摘要。迟到或非当前持有者不能落库。页面仅在当前依据展开后请求，等待中最多轮询 12 次。

停用新生成可移除本地模型或密钥配置并重启 Python，已有说明仍可读取；回退时保留版本化读取支持和全部历史说明，不执行删除历史的降级迁移。此次未改变预测结果、训练流程或收益核对。
