## 更新规则

这是实施者维护的进度文件，不是应用自动更新的监控面板。

1. 开始一步：改为`▶ 进行中`，填写开始时间，更新上方当前阶段/正在做/下一步，并追加变更日志。
2. 写好代码但缺必要检查：改为`◐ 待验收`，列清未验证内容，不能填写完成时间或加完成数量。
3. 等真实窗口、数据或到期：改为`⏳ 等待条件`，写具体日期/触发条件及继续推进的独立步骤。
4. 真正受阻：改为`⛔ 受阻`，记录错误、已试方法、不能继续的准确原因和下一步；不要只写“待确认”。
5. 完成：改为`✅ 已完成`，必须有对应方案完成条件的证据路径、证据类型和完成时间，同时更新总数。
6. 发现回归：重新打开步骤，保留原证据并记录原因，完成数扣回；不通过删难项改变分母。

所有时间使用北京时间`YYYY-MM-DD HH:mm:ss +08:00`。实施步骤、验收项和长期观察分别统计。受控夹具不能替代该项要求的真实运行证据。
