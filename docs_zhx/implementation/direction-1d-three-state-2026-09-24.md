# 一日预测拆分持平与下跌

## 范围和口径

新的一日预测使用 `DIRECTION_1D_V2` / `UNIT_NAV_DIRECTION_THREE_STATE_V2`，保留独立的一日训练及推理，不改变 5 日、20 日、半年模型。按原始十进制单位净值比较：增加为 UP，相等为 FLAT，减少为 DOWN；不另设未经用户要求的“微涨微跌也算持平”范围。

原 `DIRECTION_1D_V1` 预测和评分原文不覆盖、不改标签。三分类模型重新训练三组系数，不能用二分类分数划出一个区间冒充持平。新旧记录分别校验，成绩按协议分组，旧记录继续按原二分类口径核对。

## 实现与异常边界

- Python 新增三分类协议、训练及登记模块，复用原七项输入、训练数据范围和产品家族权重。训练仅使用既有 2021—2024 开发历史及已核对的前向样本；2025 保留保护状态，不回填 2026 历史训练数据。
- 新模型使用独立 cohort、作业幂等键及原文版本。每组要求至少 252 个交易日期及各类至少 30 个家族日期样本，数据不足则不可用，不退回旧二分类伪装三分类。
- 独立时间段开发检查、原系数还原以及同配方复现后登记；这些验证不代表独立未来准确率提高，保留实验状态。
- Java 接受两版原文，核对三类分数与最高类别、协议及日期。新生成只复用当前协议；旧档案仍可查询。当前预测同日优先新版本；历史列表保留既有日期和编号游标。
- 前端新预测分别显示上涨、持平、下跌；旧记录继续明确包含持平。依据展示核对原模型身份并使用三类系数差解释支持和反对作用。
- 一日成绩、各类别召回率与基准按协议分别统计，避免二分类与三分类混算。

无需修改原表的业务主键；现有主键含协议和 cohort，分数原文支持 JSON 三类分数。新增迁移仅补充协议查询索引与字段说明，不删除或回写旧数据。

## 验收

核对 UP/FLAT/DOWN 三种真实输出、微小涨跌不被显示舍入吞并、并列规则、缺类拒绝、旧档兼容、历史成绩不混算、解释身份校验、真实训练登记和本地服务调用。正式未来准确率需要新预测到期后另行统计。
