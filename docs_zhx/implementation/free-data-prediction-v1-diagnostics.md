# 预测 V1：为什么校准后没有变好

> 日期：2026-09-08 ｜ 性质：对既有实验的只读复盘，不是新模型或发布验收。
> 关联：[实施手册第16节](free-data-prediction-v1.md)、[测试用例TC-FDP-18](../testcase/free-data-prediction-v1.md)。

## 1. 先说结论

现在有两类发现，不能混为一谈：

- **模型表现：** 校准器在一段上涨较少的历史里学出了偏向“不涨”的映射，而且基础得分与实际方向的平均关系换了方向。换到2024年，这个映射不适用，分数误差变大。这是有数据支持的失败机制线索，不是已经证明了唯一根因。
- **数据口径：** 源净值有周末业务日期，累计净值与复权净值也不完全等价；历史首次可得版本仍不能还原。这些是正式准入必须处理的问题，但不能直接说它们造成了本次全部误差。

因此，下一步先核准“20个交易日”和净值口径，不继续根据已经看过的2024成绩反复换模型参数。2025仍不评分，当前模型不发布。

## 2. 模型具体错在哪里

### 2.1 校准段和考试段并不一样

以2024验证这一个窗口为例：

| 看什么 | 校准段：2023年下半年 | 考试段：2024年 |
| --- | --- | --- |
| 样本数 | 312 | 660 |
| 实际上涨数 | 92 | 326 |
| 实际上涨比例 | 29.49% | 49.39% |
| 校准后平均上涨分数 | 29.49% | 23.78% |
| 校准后判为上涨的数量 | 3 | 10 |

“平均分数29.49%贴近校准段实际29.49%”并不代表模型掌握了可靠规律，因为这就是校准器拿来学习的那段历史，属于**样本内表现**。真正换到没有参与拟合的2024，实际接近一半上涨，它平均只报23.78%，660条中只有10条分数超过0.5。

这里的“分布变化”说人话就是：前一段历史涨得少，后一段涨得多，模型面对的情况变了。但只是上涨比例变化，还不足以完整解释全部问题。

### 2.2 不只是整体偏低，映射方向也不稳定

基础模型会先计算一个线性得分`z`。诊断比较“真实上涨样本的平均z”减去“真实非上涨样本的平均z”：

- 2024窗口的基础拟合段：`+0.5933`，平均上是上涨样本得分较高。
- 独立校准段：`-0.2868`，平均关系反过来了。
- 2024考试段：`+0.1791`，总体平均关系又回到正向。

校准器仅在第二段学习，学到的斜率是`-0.6864`，也就是基础模型分数越高，它反而倾向把分数往低处调。这个负向映射带到总体平均关系恢复正向的2024，自然值得警惕。

以上是描述统计，不是因果证明、显著性检验或每一条样本都满足的规则。三基金的关系也不完全相同，不能直接推出“强制把负斜率改正就能解决”。本轮没有裁剪斜率或重新训练。

### 2.3 三只基金都变差，不是单个基金拖累

Brier是分数与实际0/1答案之间的平均平方差，越小越好。它不只衡量校准，所以这里只作为误差证据之一。

| 2024基金 | 校准前Brier | 校准后Brier | 校准后判上涨 / 样本数 |
| --- | --- | --- | --- |
| 001632 | 0.26308257 | 0.34312551 | 0 / 220 |
| 006730 | 0.25679011 | 0.31607580 | 0 / 220 |
| 008888 | 0.30552911 | 0.35088503 | 10 / 220 |

前两只基金校准后每条都判“不涨”。其中006730依然有55%的准确率，是因为它这段本来就有55%的样本不涨，不表示模型能有效区分涨跌；它的平衡准确率恰为0.5。

### 2.4 四个季度也都变差

| 2024输入公告季度 | 样本数 | 校准前Brier | 校准后Brier |
| --- | --- | --- | --- |
| 第一季度 | 174 | 0.28893766 | 0.37850248 |
| 第二季度 | 177 | 0.20561393 | 0.33771597 |
| 第三季度 | 189 | 0.26787936 | 0.27258097 |
| 第四季度 | 120 | 0.36908648 | 0.37555027 |

这里仅把原来的660条考试样本拆开，四组数量相加仍是660；不是新训练四个模型。分组用输入实际可得日，答案允许跨季度，但不能越过原来2024年末的截止；第四季度不是完整季度的所有净值日，年底未成熟答案已剔除。

### 2.5 七个输入指标检查了什么

脚本固定报告全部七列的均值、相对训练尺度的偏移、超出基础拟合段最小/最大范围的比例，以及对当前模型线性得分的绝对数值贡献。

- 2024整体的七列均值偏移最大约0.357个训练尺度，出现在20日收益指标；这只是均值，没有证明联合分布或尾部不变。
- 20日波动率约6.06%的考试输入超出基础拟合范围；20日收益约3.79%超出范围。不能仅凭这个比例认定数据错误。
- 当前模型中60日相对位置的平均绝对线性贡献较大，但七项指标存在关联，不能因此断言它是失败原因或直接删除它。

本轮没有做基于2024答案的特征筛选、自动排名选模型或反复试参数。

## 3. 数据核验发现了什么

### 3.1 已存样本能重现，但这不等于当年可得版本正确

读取同来源三基金2021–2024年当前净值，共2922行；2021仅提供2022起点需要的历史。逐一重放已纳入的2022–2024训练/验证行，每基金679条，共2037条：输入七项指标、上涨方向及输入/答案可得日期均一致，未发现这些字段的重放差异。

这是**当前快照的一致性验证**，没有比较所有原始字段或证明每个收益金额正确。相同算法复算一致也不是独立金融公式认证。

这2922条记录的`source_published_at`全部为空，本地创建时间在2026-08-27；`ann_date`虽完整且不早于净值日，也不能单独证明当前数值就是该公告日首次公布的数值。
静态代码还确认：`upsert_nav_daily_batch`发现内容哈希变化后，会覆盖同基金/日期/来源的现有净值和公告字段。当前净值主键只保留一个版本，项目本次核验没有找到配套净值历史版本表。

以后开始保存首次抓取和后续修订版本可以改善今后的追溯，但**不能倒过来补证2022–2024的首次版本**。现有来源同步记录也不能代替逐条历史版本证据。

### 3.2 “20条净值”确实不完全等于“20个交易日”

三只基金的当前净值中均出现这五个周末业务日期：

```text
2022-12-31、2023-09-30、2023-12-31、2024-03-31、2024-06-30
```

当前标签直接数起点后面的20条净值，不按交易日历过滤，因此每基金80条已纳入的训练/验证样本，其未来20条中至少包含一条周末净值；三基金共240条。

这不表示这15条源记录应该删除：它们可能是合法的期末估值记录。问题在于模型的时间窗口如何计数。也不能只跳过周末就宣称完成了交易日历核验，节假日、缺数和公告延迟仍要处理。

本轮没有删除净值、改标签终点或重存样本。现有研究协议继续按“20条有效净值”解释；若要严格落实产品的20个交易日，应建立新规则版本，保留旧版本可复现。

### 3.3 累计净值和复权净值不能直接互换

来源官方将`accum_nav`定义为累计净值，将`adj_nav`定义为复权单位净值，是两个不同字段；本地同步分别写入`accumulated_nav`和`adjusted_nav`。[Tushare净值字段说明](https://tushare.pro/document/2?doc_id=119)

本轮只在相同起点和终点上做敏感性比较，不切换模型输入或替换答案：

| 基金 | 比较窗口数 | 两种口径方向不一致数量 | 收益差绝对值最大值 |
| --- | --- | --- | --- |
| 001632 | 679 | 0 | 约1.165个百分点 |
| 006730 | 679 | 1 | 约10.218个百分点 |
| 008888 | 679 | 0 | 0 |

一个可手算的差异是`006730，2023-06-14 → 2023-07-14`：

- 累计净值：`1.7907 / 1.7896 - 1 ≈ +0.06147%`。
- 复权净值：`1.81367369 / 1.81493729 - 1 ≈ -0.06962%`。

只能确认两个当前字段给出不同结果，不能据此认定哪一个历史版本正确。绝大多数方向相同也不代表七项输入指标不受影响；复权定义、分红事件完整性和历史版本仍需专门核验。没有用另一套口径重新训练来挑更好成绩。

### 3.4 试点代表性与授权边界

当前本地资料显示：001632是食品饮料ETF联接，008888是芯片ETF联接，均为被动指数型；006730为中证500指数增强。这三只基金足够验证工程流程，但不能代表全部股票型基金，当前资料也不是历史分类版本证据。

来源本地登记仍启用，登记有`fund_nav`授权API和2026-09-05核验时间。本轮没有访问供应商账户、验证账号权限或法律条款，也没有调用采集接口。不能把读取到登记信息写成“已重新取得训练/展示授权”。

## 4. 下一步的顺序

1. **先明确交易日计数契约。** 确认以哪个截止点起算，取得适用且可追溯的交易日历，核验期末非交易日净值、节假日和漏数。不能把其他基金都有记录的日期集合冒充权威完整日历。
2. **再核准净值口径。** 查清累计/复权字段、分红处理和数据版本，确定研究目标到底是净值方向还是可比持有收益方向；不能按哪种口径让模型分数更好来选。
3. **版本化后再出新样本。** 不修改原始净值、不覆盖旧批次；有完整契约与证据后才用新规则另存样本，保留现在的模型和失败报告。
4. **数据契约稳定后再改模型。** 依据新数据覆盖与误差证据冻结下一种研究方案；2024已经多次被观察，不把它当全新最终测试，2025继续保留。

这一步只完成诊断，没有实施以上数据接入、日历规则、样本重建或模型变更。历史首次版本证据未闭环前，仍只能研究，不能通过技术检查自动解除正式准入。
