## 4. 持平范围与分类契约

### 4.1 统一计算含义

R 表示从预测观察起点 S 到目标日 E 的现金分红再投资总回报，沿用现有计算公式。T 表示这一预测适用的持平范围，必须为有限、严格大于零的收益率。

| 条件 | 接口方向 | 页面文字 |
| --- | --- | --- |
| R > T | UP | 上涨 |
| -T ≤ R ≤ T | FLAT | 持平 |
| R < -T | DOWN | 下跌 |

- 恰好等于正、负边界均为持平。
- 内部单位为收益率小数，例如 0.003 对应 0.3%，不是 0.003%。方向先按未展示舍入的精确值判定，再格式化百分比。
- 举例只用于解释：如果某周期采用 ±0.3%，则 +0.2% 和 -0.2% 均为持平，+0.4% 为上涨，-0.4% 为下跌。本轮五日已采用这个范围，其他周期见下表。
- 模型的上涨得分接近 0.5，不表示未来收益在持平范围内。不能给旧二分类分数随意加一段“持平区间”冒充三分类。
- 预测阶段输出的是对上述类别的判断；实际 R 要等到目标期满并且资料齐备后才能计算，不能使用未来答案作为当前输入。

## 6. Java：建议、回放与服务接口

### 6.1 持平的建议含义

| 预测方向 | 方向信号 | 解释 |
| --- | --- | --- |
| UP | +1 | 正向依据 |
| FLAT | 0 | 中性依据，代表预计小幅波动 |
| DOWN | -1 | 负向依据 |

- FLAT 是有效预测，其周期权重仍进入总权重分母；不能把它当作缺失后删除权重，进而放大剩余涨跌信号。
- 缺预测、未知方向、不兼容目标不能默认为中性。没有可用必要预测时沿用明确失败，不生成假“持平”。
- 中性依据不放入“看跌/反对持有”文案；支持、反对和中性说明应清楚区分。
- 修正总分为零的动作边界：有持仓且没有其他负面因素或个人规则触发时，零分应继续持有；无持仓时不因持平产生买入建议。
- 持平不等于任何情况下都继续持有。现有止盈、回撤及其他真实负面因素仍可使最终建议为减仓/卖出，原因要准确说明。
- 不借此修改费用、份额、资金结算和模拟交易账户逻辑。

主要文件：DecisionPolicyV2.java、DecisionServiceV2.java、prediction-policy-v1.json、相关接口及测试。采用新的策略版本，明确允许接收的预测目标及方向规则，不能仅接受三个字符串后无条件计算。
