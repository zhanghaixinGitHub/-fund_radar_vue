## 类别与候选规则

| 类别 | 已实现的专用输入与计算 | 正式开放 |
| --- | --- | --- |
| 主动权益 | 分红/折算总回报、下行与回撤、同币种无风险收益、滚动稳定性、完整团队、发行人/行业集中、五日变现、全部费用 | 否 |
| 纯债、短债、混合债券 | 信用压力、久期与凸性、较低信用资产、债券可交易额；混合债券增加目标配置偏离 | 否 |
| 可转债 | 权益压力及转股溢价、发行人集中、可转债成交流动性 | 否 |
| 被动指数 | 同目标、同币种、同日期总回报跟踪误差/偏离与持仓复制偏离，不要求主动跑赢 | 否 |
| 货币基金 | 实际收益分配再投资、信用/利率压力、到期及可赎回资产；不对恒定净值套普通夏普 | 否 |
| 境外权益、境外债券、境外商品 | 市场日历/时区/汇率口径/赎回限制；对应权益、债券或商品规则，商品含交易对手和展期成本 | 否 |
| FOF | 底层穿透集中与重叠、配置偏离、底层赎回、扣除已证实减免后的内外层费用 | 否 |

这些是可运行的候选适配器，已用隔离算例验证输入和运算边界，**不是各类别真实资料验收通过**。无法可靠细分的其他类型不套用最相似公式。当前权益适配器要求支持资产完整对账；含未支持资产的混合组合会阻断，不能将未知资产当现金。

文档提出的 36 个月、30 个产品、前 5 个交易日宽限、持仓 210 日、经理/费率核对 31 日、五日变现及 10% 成交参与率均仍是候选。专用压力情景和类别权重同样没有被宣称为行业标准。真实合格样本为零，因此没有可报告的真实四级分布、敏感性或相关性，也没有执行激活。阈值四级映射和八维全部参与属于已确认产品要求，已固定。
