# 1日统一模型对照与盘中更新数据检查

用户在2026-09-12明确要求按建议继续训练、优化模型。本轮先回答两个具体问题：统一模型是否优于当前3组模型；给统一模型加入基金类型信息是否有帮助。以下方案在本轮拟合前固定，实际结果另附，不改旧模型、14日真实预测或20日研究。

## 本轮固定对照

| 方案 | 参数与输入 | 新增拟合 |

| GROUPED_7 | 原3个分组模型的冻结季度分数 | 0，复用并验hash |

两种新方案各最多5次主拟合、5次相同输入复现，总计10＋10；不搜索参数、不修改0.5方向阈值、不根据本轮成绩删基金或挑季度。L2逻辑回归C=1、lbfgs、tol=1e-8、max_iter=1000、seed=0；标准化仅在FIT拟合，沿用产品家族和日期权重、单数值线程。

使用旧首模运行包direction-1d-initial-20260911的冻结历史/样本。四个2024季度使用对应旧3组FIT的精确并集，并核验每组FIT哈希及全部61日输入公告时间；两种统一方案使用完全相同的FIT和EXAM。FINAL仅产出研究模型，不写在用模型注册表。2021—2024已经是开发数据，2025保护排除，2026回溯不使用，14日答案尚未到期。

考试只保留输入公告时间假设不晚于目标日08:00的共同题目；公告只有日期，08:00是假设，不能冒充历史首次实际收取时刻。旧373题时间不合格题继续排除，不覆盖旧报告。

同时报告原始准确率、家族日期加权准确率、上涨/非上涨召回率、均衡准确率、按季度/资产组/基金结果、持平数，以及恒上涨、恒非上涨、初始组内多数类、昨日方向延续四个基线。初始多数类取2024Q1各组FIT并保持不变。本轮主要比较家族日期加权准确率；以目标日为块做5日块重采样，保留同日基金相关性，固定seed=20260912、2000次，区间仅作开发期不确定性参考。

只报告哪个方案在这批开发题上更好、差异是否稳定。没有把复现一致或开发成绩直接当成未来有效；本轮不改FIXED/WEEKLY配方、不覆盖已留档14日预测、不自动正式发布。

## 一天多次预测的数据结论

已读实际source_registry：TUSHARE_PRO_FUND授权接口为fund_company、fund_basic、fund_nav、fund_manager、fund_share、fund_div、fund_daily、daily、daily_basic、index_basic、index_classify、index_daily、index_weight。没有分钟行情和新闻授权；旧库日线不能还原11:30、14:30当时所见输入。

[Tushare指数历史分钟接口](https://tushare.pro/document/2?doc_id=419)明确需要单独权限。本轮不申请新权限、不购买、不绕过来源登记；未调用未授权分钟接口。这不等于已确认供应商账户没有分钟权限，而是当前项目授权范围不足。

盘中实验拟比较08:20（盘前）、11:30、14:30三个北京时间截点，分别预测同一目标日收盘单位净值方向。启用前需有各截点对应的实际行情、可核验时间、历史分钟样本和对应基金/指数映射；每一截点的原文、模型和成绩分开保存。当前状态为DATA_AUTHORIZATION_PENDING，未启用三个无新信息的定时重复计算。

本轮本地研究沿用Python与设计工程Skill，不涉及新Java/Vue业务接口、生产、交易或对外通知。三仓既有未提交工作保留，不提交推送。
