## 怎样看完成标志

| 标志 | 含义 | 能否计为完成 |
| --- | --- | --- |
| ☐ 未开始 | 还没有开始实施这个步骤 | 否 |
| ▶ 进行中 | 正在实现或处理，尚未全部完成 | 否 |
| ◐ 待验收 | 代码或配置已做好，但必要检查尚未通过 | 否 |
| ⏳ 等待条件 | 等数据补齐、真实生成窗口或预测到期；要填写具体条件/日期 | 否 |
| ⛔ 受阻 | 有明确错误或缺少外部条件，暂时无法推进；要填写原因及下一步 | 否 |
| ✅ 已完成 | 该行的完成条件全部满足，证据和完成时间已填写 | 是 |

不能只因为代码写好、模型训练完、文档写完，就把“页面实际采用”“真实接口验证”等步骤一起打勾。任何步骤部分完成，仍保留未完成状态，并在证据栏写清已经做到什么。

如果完成后发现回归问题，将状态改回进行中或受阻，保留原证据和重新打开的原因，总数同步扣回。拆分或新增步骤时记录原因并更新分母，不为了提高完成比例删除困难步骤。
