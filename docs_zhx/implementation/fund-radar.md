### 已确认的原则

- Java 负责对前端的业务接口、用户关注、提醒、审计和 Java → Python 内部服务的调用。
- Python 使用 FastAPI + Pydantic + SQLAlchemy/Alembic + Celery，负责数据采集、AI 分析、回测和内部接口。
- 一期先做全市场基金雷达；不要求导入支付宝持仓。
- 不保存支付宝认证信息，不做网页模拟下单，不做自动交易。

### 每次恢复工作的方式

1. 先阅读本文件的“当前状态”和未勾选的当前任务。
2. 再阅读关联需求文档；涉及接口、数据或安全时，读取关联设计和测试文档的对应章节。
3. 只实施当前任务；完成代码和本任务规定的验证后，才将 `[ ]` 改为 `[x]`。
4. 更新本节的“最近更新、已完成的实施任务、当前任务、下一步操作、当前阻塞”。
5. 若失败或需要用户决定，不勾选任务；在“变更/阻塞记录”追加事实、影响和恢复条件。
