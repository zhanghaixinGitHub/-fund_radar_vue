## 3. 特征组合确实可能影响结果，但尚未证明是主因

用户提出的机制成立：一个公司的好消息不直接等于整个基金次日上涨。需要明确消息影响哪家公司或业务、影响方向与持续期间、当时可知的持仓权重、其他持仓和共同市场因素，以及这是否是价格尚未包含的新信息。

例如仅作加权算术说明：某股票占10%，当天上涨5%，贡献约+0.5个百分点；其余90%资产若下跌1%，贡献约−0.9个百分点，合计约−0.4个百分点。例子没有把新闻情绪直接换算成可知的未来收益，也忽略了费用与更复杂交易，只说明“局部上涨不保证基金上涨”。

现有A/B/C/W20/I24没有新闻文本、公司财报或公告语义输入，不能将旧成绩解释成“模型把新闻读错”。[现有模型计算](C:/pythonProject/workSpace06/app/services/fund_002112_training_model.py:104)先标准化，再把各项输入乘权重相加得到三类分数；I24只多了4个股票仓位与市场涨跌乘积。它们没有实现上述新闻到公司、公司到组合的完整分析链。

这支持“有些信息和关系尚未表达”的判断，尚不支持“换复杂组合必然改善”。原诊断还表明60日净值走势推动C偏上涨、自身资料与开发期股票仓位差异明显；不能把错误全部归给持仓、大盘或一种算法。

营业收入增长是已公布的经营事实，不等于超出市场预期，也不直接等于次日股价上涨。刚补齐数字，只能说明输入可取得，不能说明有额外预测价值。

## 4. 怎样定位问题，而不是只凭猜测

| 检查层 | 能直接核查什么 | 不能由此推出什么 |
| --- | --- | --- |
| 事实与日期 | 原文、报告期、单位、公司代码、公开日期、修订版本、累计/单季是否正确；本次已找到“不适用”和两个漏字段 | 字段正确不等于能预测次日 |
| 消息含义与关联 | 摘录支撑句、涉及的公司/业务、利好利空针对谁、发生事实还是预测、作用于何种期限；找不到证据则写未知 | 把文本理解正确不等于知道市场尚未计价的部分 |
| 组合计算 | 按当时公开持仓逐项列出贡献、分母和未覆盖部分；检查符号、权重、遗漏与重复计算 | 用旧持仓报告不能确认当天真实交易与仓位 |
| 现有模型行为 | 还原每项对上涨/持平/下跌分数的贡献，检查偏向、类别错误和时间段差异；原C已有60日走势诊断 | “什么推动模型这样猜”不等于“市场为何这样走” |
| 新信息的增量 | 条件合格后，在预先固定的共同日期、同一方法下，只增加一种信息，与匹配对照比较 | 一次成绩改善不证明市场因果，也不保证未来持续 |
| 组合方式的增量 | 使用完全相同的信息和日期，另行预先固定一种组合变化，保持其他条件一致 | 不能同时换资料、样本和算法后把改善归因于某一项 |

缺数、错单位、错公司、方向符号错误等可以确定性定位；表示方式与预测能力要靠受控比较获得证据。市场还有截止后新发生的事和未观察因素，单日误判不一定存在可唯一追溯的程序错误。故研究需要试验，但不应没有假设地不断加特征、换算法、看成绩再解释。
