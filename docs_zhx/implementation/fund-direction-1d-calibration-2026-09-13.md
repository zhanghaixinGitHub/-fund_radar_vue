# 一日模型固定分数校准研究方案（拟合前冻结）

本轮目标是检验原12项研究树经过一次固定校准后，是否真的少判断错，并分别说明分数可靠性变化。用户已要求先提交推送现有代码再开始下一轮；Python `e7b849a`、Vue `4e25de9` 已推送，Java无新改动。新研究不替换在用模型。

## 1. 固定假设与范围

- 唯一候选 `SIGMOID_LOGIT12`：对原 `ACTIVITY12` 的上涨分数做 `sigmoid(a × logit(p) + b)` 修正。仅学习两个系数，不增加输入、不重新训练树、不按结果搜索算法或阈值。
- p仅为研究分数，logit前固定裁剪到[0.000001, 0.999999]。使用现有scikit-learn的LogisticRegression，C=1、solver=lbfgs、max_iter=1000、tol=1e-10、fit_intercept=True、class_weight=None、random_state=0；使用原家族日期权重，L2默认正则化，系数允许正负。若不收敛直接失败，不追加训练预算。
- 沿用完整样本研究的25只基金、6,025道2024题、241个目标日和原单位净值上涨/非上涨定义。平盘计非上涨，分数严格大于0.5才判断上涨，不删题、不设置不确定或筛选展示。
- 此前已调过0.45/0.50/0.55判断线，未见稳定提升；本轮是固定的两参数分数映射，不扩展该阈值搜索。分数变保守但方向未改善，不称为精准优化成功。

## 2. 时间隔离与预算

复用 `direction-1d-full-threshold-20260912` 的16个已训练ACTIVITY12模型：每季度前63个成熟目标日，分三块，每块21日；每块分数由更早训练且没见过该块答案的模型生成。校准器只接收这些折外分数及已成熟答案，不接收随后季度答案。校准后作用于原季度树的随后题。

先校验原模型、成员、来源有效期、时间、代码指纹和唯一复现，冻结方案及输入；再做4次主校准拟合及唯一4次复现，系数与全部分数必须一致。复核和评估零拟合；输出不可覆盖；不增加FINAL拟合。2025/2026答案不解封，原历史净值08:00、行情18:00可用假设及首版本证据不足继续保留。

## 3. 验收口径

- 主要目标：全题正确数/准确率、上涨与非上涨识别率；按季度、基金、分组、月份和恢复321题报告。采用同目标日整组5日块、2,000次、seed=20260913的配对探索区间；6,025条不是6,025次独立行情。
- 沿用事前观察条件：整体提高、配对区间下限>0、至少3/4季度和17/25基金提高、最差基金不低于原模型5个百分点、两类识别率均不下降。全部满足也只称开发观察条件满足，不作正式发布依据。
- 次要目标：固定上涨分数10档及把握分数[0.50,0.55,0.60,0.65,0.70,0.80,1.00]各档的样本数/目标日数/分数均值/实际比例；报告加权Brier、log loss、分档绝对差及其季度变化。Brier/log loss不能单独等同于校准好坏。
- 固定>=0.70为高把握诊断，分别记录数量、错误数量、错误占全体比例及该组内部错误率；同时跟踪原高把握题在校准后的实际方向正确数。分数压低造成高把握题减少，不能被算作多答对。
- 真实未来表现仍需固定方案后的新预测核对。已有早间采集任务继续运行，本轮不改其契约、排程或历史时间审计。

方法依据：[scikit-learn概率校准](https://scikit-learn.org/stable/modules/calibration.html)、[LogisticRegression接口](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.LogisticRegression.html)。使用时间顺序明确的既有折外窗口，不使用随机交叉验证。
