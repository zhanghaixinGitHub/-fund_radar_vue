# 一日基金每周更新频率固定训练方案（2026-09-12）

本轮承接成交活跃度研究，仅比较每周重训与已封存的季度版本；先提交推送成交额代码和文档，再执行本轮。上一轮 Python `15a043f`、Vue `990dfa2`、Java `70c0816` 已核对远端一致。此文件必须在第一次真实拟合前封存，不根据成绩改写。

- 目的：原11项浅树和成交额12项浅树，分别检查更频繁使用已知答案是否改善下一交易日单位净值方向。
- 范围：沿用成交额研究的25只基金、5,704道题、229个目标交易日，包含79个平盘答案；不删除表现差的基金或季度。全部关注43只的范围另行完整报告。
- 数据：仅既有2021—2024封存数据；2025受保护、2026仅真实前向。无新增接口调用、补数、数据库写入或来源权限变更。沿用最早来源留存截止2027-09-09 12:04:31.392479 UTC。
- 配方：两条分支均保持原100轮、深度2、最多4叶、学习率0.05、叶子最少100样本、L2=10、63桶、随机种子0、无早停。仅成交额分支多一个T日成交额/此前20交易日平均成交额−1；不追加近期权重。
- 周界：根据目标U日所属自然周，使用前一周日北京时间12:00的模型。同一自然周不再重训。2024-01-02用2023-12-31中午截止，2024-12-31用2024-12-29截止，不能因ISO周跨年解封2025。
- FIT：净值答案成熟且61日净值输入公告在截止时刻可用后，按原分组选择最近504个交易T日，再应用原映射日期和固定基金范围。对应指数、沪深300、成交额可用时间也不得晚于该截止。各周两分支使用同样的行与产品家族×日期权重；不按标签挑样本。
- 标准化：每周仅在该周FIT计算前11项尺度，两分支逐值共用；成交额另由同一FIT拟合第12维尺度。两条都是跨这25只基金合并训练，每周是模型版本，不是逐只基金各训一个模型。
- 考题：原5,704题和季度参考分数原样复用；预测输入截至T，目标是下一交易日U。每周模型截止早于U日08:00；指数T日18:00、净值公告日08:00仍为历史可用假设，非过去真实收到的证据。
- 对照：季度原树、季度成交额树、每周原树、每周成交额树。旧季度模型保留原截止时刻，本实验衡量采用周日更新日程的整体影响；周界处信息截止也相应变化，不能将全部差异归因于纯粹次数。旧季度模型和简单基线不重新训练。
- 固定预算：预检得到50个有考题的周；两分支合计主训练100次、唯一同配方复现100次。无考题的周不需要拟合，无额外FINAL模型。分类器拟合前逐次写入占用凭证；技术失败保留现场并说明，不暗中重试或替换参数。
- 比较：事先固定“每周原树对季度原树”“每周成交额树对季度成交额树”“每周成交额树对每周原树”三组；主口径为产品家族×日期加权准确率，同时给原始对题数、双向召回、季度与基金分布。沿用按目标交易日整体抽样的5日块、2,000次、种子20260912区间，不只挑最好的一组汇报。
- 验证：输入封条与代码指纹、周成员和权重、完整FIT/考题JSON恢复、唯一复现逐值相等；补充周界、延迟公告、成熟边界、504日窗口、预算重复与模型篡改测试。旧研究、其他对话详情页、真实预测数组和运行模型注册表前后哈希核对。
