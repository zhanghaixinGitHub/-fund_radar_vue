2026-09-11 用户授权开始下一轮训练，并通过既有 Tushare 接口补齐缺少的对应指数。本文在新增指数日线读取及拟合前建立。

完成状态：已补齐三个指数的 2,907 条日线，原 1,389 题全部保留。A/B/C 准确率为 56.59%/55.80%/56.80%，无合格候选；24 次主拟合和等量复跑、184 项相关测试及封存复算完成。详细结果、原始产物位置和复核命令见[验收记录](../reviews/direction-matched-market-2026-09-11.md)。以下保留事前固定方案。

## 固定方案

沿用三基金、2021—2024 开发数据、2023Q1—2024Q4 八季度和原训练截止；目标为恰好20交易日现金分红再投收益是否大于零。阈值0.5，StandardScaler加L2逻辑回归、C=1、lbfgs、tol=1e-8、最多1000次迭代，基金等权。保留七项净值输入。

| 分组 | 固定输入 |
| --- | --- |
| A / REFERENCE | 原七项，作为同题对照 |
| B / SHARED_MARKET | 七项加统一沪深300的20日收益、20日波动、基金减指数同期收益 |
| C / MATCHED_MARKET | 七项加各基金对应指数的同三项市场输入 |

主实验最多24次拟合，等量复现最多24次；每作业120秒、4GiB提交内存、单数值线程，总拟合阶段30分钟。没有新增参数、阈值、层数或按单基金成绩挑分支。

## 数据和实验边界

- 复用旧研究包中969条沪深300日线。新增三个指数使用Tushare index_daily，2021—2024逐年查询，最多12次，不自动重试或更换数据源。已有index_basic最小查询取得本地缺失的930653.CSI，按既有仓储只补这一条目录，并读回核验。
- 原始行情保存在有日期、请求范围和文件摘要的本机研究包，不写入正式模型基准或预测表。无需新增表、来源账号、付费、定时任务、页面或服务重启。
- 指数日期需与基金信息锚点一致。特征使用截止日前一交易日结束的21个收盘价，计算20段收益；不补缺失、不迁移日期、不使用截止日收盘。历史首次版本尚未证实，沿用下一交易日结束前可得的研究假设。
- 三组FIT和EXAM题键一致；若市场缺数，同步移除三组对应输入并保留缺失原因与计划分母。原全题A成绩单列，避免把删题造成的变化说成模型改进；训练样本未变时逐项核对A的系数、标准化参数和预测分数。
- 保持FIT252、间隔成熟60、EXAM40、共同覆盖90%、至少3个有效窗口及5个完整20日块；相对原模型及五个简单对照的准确率增益区间下限为正、平衡准确率不退步，多数基金及至少2/3窗口改善，单基金下降不超过5个百分点，Brier恶化不超过0.01。失败作业保留并否决准入。
- 增补C对B的配对比较及误报、漏涨转换。C胜A不等于基金匹配有效。无合格候选就结束这轮假设；若合格先封存候选，独立性和来源条件仍需满足，不能自动发布。

## 复核入口

Python入口为 `scripts/direction_market.py` 的 freeze、acquire、prepare、predict、score、finalize、verify、replay。按window拆分预测JSONL，每文件不超过既有1万行限制。verify只读封存文件、复建输入并复算评分，不联网、不连接数据库、不拟合。旧协议、旧研究包及当前页面的固定模型保持原有含义。
