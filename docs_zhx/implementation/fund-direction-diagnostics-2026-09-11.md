# 预测训练诊断：事前规则

用户要求解释训练表现与评价表现，并实际诊断样本量、基金差异和时段变化。本轮目标是缩小失败原因范围，不以找到新候选为结束条件。评价表现指模型预测未参与该次拟合的历史日期，再与随后真实20交易日收益方向比较；当前评价日期已被多轮研究观察，不是未来实盘或独立测试。

保留三只基金001632、006730、008888，原七特征、C=1线性模型、20交易日目标、0.5阈值、八季度及每基金463道评价题。所有新增训练标签仍须在原FIT_END前成熟，EXAM答案不传给worker。没有新数据获取、2025/2026数据读取、数据库写入、模型发布或页面替换。

## 2. 样本量与时间跨度对照

原每基金训练量N依次为278、343、403、462、521、585、645、703。每季度固定以下四种情况：

| 情况 | 每基金样本数 | 选择方法 | 是否新增拟合 |
| --- | ---: | --- | --- |
| FULL_REUSED | N | 原全部FIT | 否，复用旧模型 |
| SPREAD_252 | 252 | 保留首尾、按日期索引不断平分最大间隔，覆盖原历史跨度 | 是 |
| SPREAD_MID | floor((252+N)/2) | 同一嵌套日期选择序列，包含SPREAD_252 | 是 |
| RECENT_252 | 252 | 原FIT中最近252个日期 | 是 |

选择只依赖输入日期，不看特征值、标签或评价成绩；三基金使用完全相同日期。SPREAD_252、SPREAD_MID与FULL构成三档样本量诊断，保留相同首尾时间。RECENT_252对SPREAD_252保持样本数相同，比较集中近期与覆盖较长历史的差异。任何训练组仍至少252条/基金，不放宽旧模型的基本输入校验。

这些对照只能提供诊断线索：增加样本也改变日期密度、标签重叠程度与市场阶段权重；C固定时，正则项相对全部训练损失的作用也可能随样本量变化，应解释为固定训练器的学习曲线，不能声称纯粹识别了独立样本数的因果效应。初始季度三档数量接近，另单独报告2024四季度。原FIT到EXAM之间约半年间隔保持不变，近期组并未补入这段已成熟数据，不能称为检验了每月更新模型；此前补近期实验仍作为已知证据。

最多24次主拟合，唯一一次复跑最多另24次；复用原八套模型不计新增拟合。每任务120秒、4GiB、一个数值线程，整批拟合1800秒，任何失败保留并终止，不追加参数或另挑样本。原算法、标准化和数值JSON重放沿用已有实现。

## 3. 诊断指标与解释边界

保存每组逐季度、逐基金的FIT训练表现和EXAM历史预测表现；汇总原1,389题及2024子集。增加完整时间块的三个事前比较：FULL减SPREAD_252、FULL减SPREAD_MID、RECENT_252减SPREAD_252。沿用季度分层、三基金同步、20日完整块、seed42、2000次抽样；区间仅用于开发诊断，不作为新的候选选拔规则，不将多个比较当独立确证。

复核原模型的逐基金训练/评价类别比例、相对训练期上涨频率常数对照的表现、特征与标签相关方向，以及同一日期三基金同时预测错误的分布。相关性只描述已见时段，不能解释因果或据此翻转信号。基金差异诊断不训练新分基金模型，不足以判定混合训练就是主因；若仍无法区分，明确保留未知。

## 4. 结束条件

新增拟合和一次复跑完成；从冻结输入与保存模型重新算出分数、训练指标、评价指标及诊断，结果和模型必须一致。源码、方案、输入、模型、结果分别封存，使用冻结代码目录复核历史包。

交付必须区分：已得到支持的判断、已排除的具体解释、尚不能确定的问题，以及有证据支持的下一步。诊断不保证查出唯一根因，不自动变成下一轮模型搜索；始终保留无独立验证、无发布、无自动继续训练状态。本轮不提交或推送已有未提交工作。
