## 固定假设和三组输入

本轮只验证：对应指数的成交活跃度，以及它与基金近期涨跌的组合，能否给原七项净值输入增加有用信息。指数涨跌与基金净值高度相关只是研究动机，不是成交额必然有效的证明。

| 分支 | 输入 |
| --- | --- |
| A / REFERENCE | 原七项净值特征 |
| B / AMOUNT_ACTIVITY | A 加一项：上一交易日结束的最近5日平均成交额 / 最近20日平均成交额 |
| C / AMOUNT_INTERACTION | B 加一项：原基金20日收益 ×（成交活跃度 − 1） |

五日均值包含在二十日均值中，全部取上一交易日及之前的数据。使用原始正成交额；不调窗口、阈值、剪裁范围或缺失填充值。组合项是事前固定的乘积，使同一简单线性模型可表达涨跌与放量/缩量之间的配合，不增加隐藏层。成交额表示交易活跃程度，不称为资金净流入。

## 训练、评价与预算

保留八个季度、各原训练截止、三基金和原1,389题计划。每基金训练行与评价题在三组间严格相同；若新字段缺失，需要三组同步排除对应输入，并保留原计划分母、缺失原因及原全题A成绩。A训练集合未变时，系数、标准化参数、训练摘要和预测分数须与旧A完全相等。

算法仍为训练期 StandardScaler 加 L2 逻辑回归，C=1，lbfgs、tol=1e-8、最多1000次迭代，随机种子0，基金等权、单数值线程，分数大于0.5才判断上涨。目标仍是恰好未来20交易日现金分红再投收益大于零。

最多24次主拟合、24次等量复跑；每作业120秒、4GiB提交内存，主拟合阶段1800秒。每个运行包只允许一次拟合阶段启动；任何中断或失败留下证据，不通过重入隐藏额外拟合。模型worker只接收该窗训练答案，全部预测封存后才读评价答案。

候选沿用 FIT252、成熟间隔60、EXAM40、覆盖90%、至少3有效窗口、5个完整20日块；原模型和五个简单对照的准确率增益区间下限为正，平衡准确率不下降；至少2/3基金及2/3季度改善，单基金退步不超过5个百分点，Brier恶化不超过0.01，作业无失败。按季度分层、三基金同步，固定种子42、2000次配对抽样。另报告C对B，区分成交额增益与组合项增益。
