## 4. 为什么没有选新模型

沿用固定种子 42、2,000 次按季度分层、三基金同步的配对抽样。有 19 个完整 20 日块，每基金 380 题参与区间估计；其余每基金 83 题仍计入全题成绩。目标之间存在重叠，区间用于开发比较，不能把 1,389 题看作独立试验。

| 比较 | 全题准确率变化 | 完整块变化 | 完整块变化的 95% 区间 |
| --- | ---: | ---: | --- |
| B 比 A | -0.79 个百分点 | -0.09 个百分点 | [-2.72, +2.89] 个百分点 |
| C 比 A | +0.22 个百分点 | +0.88 个百分点 | [-1.14, +2.98] 个百分点 |
| C 比 B | +1.01 个百分点 | +0.96 个百分点 | [-2.54, +4.30] 个百分点 |
| C 比始终非上涨 | -2.59 个百分点 | -2.19 个百分点 | [-11.32, +6.67] 个百分点 |

C 对 B 的区间也跨零，尚不能证明“匹配指数”本身带来稳定增益。B/C 均通过动量类对照，但未稳定胜过原模型、始终上涨、始终非上涨和训练期上涨频率这些原要求对照。没有降低门槛或追加参数搜索。
